# Threads — AI 콘텐츠 수익화
**작업 시작·재개 시 필독:** [공지사항방](../../04_COMMUNICATION/announcements/README.md)의 새·변경 공지를 읽고 본인 프로젝트/AI 확인 기록을 남깁니다. 이미 확인한 동일 내용은 반복 조회하지 않습니다.


- 실제 저장소: https://github.com/kimjae134679/Threads
- 사용자 목표: 저장 자료와 원문에 기반한 카드 자동 제작, 레퍼런스 분석, 사람 검수와 실제 성과 학습.
- 운영 흐름: `01_DISCOVERY → 02_EDITORIAL_SCORING → 03_PRODUCTION → 04_REVIEW_PUBLISH → 05_EXPERIMENTS_ACCOUNTS`.

## 재개 순서

1. 실제 저장소의 `00_START_HERE/NEXT_RUN_HANDOFF.md`와 현재 main.
2. `docs/SOURCE_CUT_DESKTOP.md`: Windows 실행·검증·현재 자료 상태.
3. `docs/INSTAGRAM_REFERENCE_GUIDE.md`: 레퍼런스 관찰과 제작 기획.
4. 필요한 경우에만 `04_COMMUNICATION/threads/T-0008-ai-content-monetization/THREAD.md`의 관련 기록.

실제 저장소 상태가 오래된 허브 기록보다 우선합니다. 이 포인터에 변동이 잦은 버전·커밋·순차 메시지 번호를 고정하지 않습니다.

## 작업 기준

- 저장 원문을 먼저 사용하고 기존 주소에서 필요한 증거만 보완합니다.
- 자료별 제목·본문·이미지·댓글의 배치를 제작 전에 기록합니다.
- 이미지 비율과 실제 내용량에 맞춘 장 크기, 안전 여백과 가독성, 중복 방지가 핵심입니다.
- 결과 생성·전체 육안 검수·실제 게시를 별도 상태로 표시합니다.
- 원문이 없거나 접근이 제한되면 원인과 다음 조치를 남깁니다. 내용을 만들어 완료로 표시하지 않습니다.
- 원본은 보존하고 최신 파생 결과와 최신 실행본을 한 곳에 모읍니다.
- 공개 참조 계정의 관찰 범위와 확보한 샘플을 구분합니다. 타인의 이미지·캡션 원본은 공개 코드 저장소에 넣지 않습니다.
- 실제 게시와 개인정보·권리 검수는 `04_REVIEW_PUBLISH`가 담당합니다.
