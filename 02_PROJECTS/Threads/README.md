## 현재 허브가 확인한 방향

- 검은 배경의 요약형 데모는 최종 사용자 결과물로 보지 않음
- 첫 장은 원문 캡처 또는 텍스트 위에 짧고 큰 제목을 합성하는 4:5 표지. 제목은 위로 올리고 얇은 검정 테두리만 사용하며 블러는 없음
- 원제목은 보존하고 표지 문구는 별도로 편집. 다음 장부터 원문 캡처 또는 글 본문 전체를 순서대로 출력
- 이미지 원문은 실제 파일 확보와 전체 본문 확인 전 `ASSETS_PENDING`. 글만 있는 원문은 사용자가 제공한 텍스트 본문으로 제작 가능
- 생성 이미지로 원문 자산 부족을 대신해 완료 처리하지 않음
- 공개 검색·인덱스·허용된 브라우저 경로와 사용자 제공 자료 사용
- 제한 소스의 로그인·접근 제한을 우회하지 않음
- 실제 게시 권한은 `04_REVIEW_PUBLISH`에만 있음
- 구현, dry-run, 예약, 외부 게시 성공을 서로 구분

## 현재 상태 확인

실제 구현과 검증 결과는 Threads 저장소의 최신 handoff와 열린 PR에서 확인합니다. 고정된 커밋·CI·메시지 번호를 현재 상태의 원본으로 사용하지 않습니다.

사용자가 검토한 인스타 표지 방향에 맞춰 제작 기능을 수정했습니다. 다음은 실제 출력물의 사용자 검토와 브라우저 제작·복원 확인입니다. 이전 Discovery 반복 작업은 사용자 요청과 현재 코드 상태를 확인한 뒤 재개합니다.
