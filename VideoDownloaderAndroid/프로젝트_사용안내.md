# 영상다운로더 · 휴대폰에서 주소부터 저장 파일까지

## 설치와 사용

1. Galaxy S22에는 [VideoDownloader-1.1.0-arm64-v8a.apk](https://github.com/kimjae134679/project-operations-hub/releases/download/video-downloader-android-v1.1.0/VideoDownloader-1.1.0-arm64-v8a.apk)를 내려받아 설치합니다. 설치 화면에서 요청하면 해당 브라우저의 **출처를 알 수 없는 앱 설치 허용**을 켭니다. `armeabi-v7a`는 오래된 32비트 기기용입니다.
2. 앱에서 **링크 추가**를 누릅니다. 직접 입력하거나 여러 주소를 줄을 나눠 붙여 넣습니다. 다른 앱의 공유 메뉴에서 영상다운로더를 선택해도 됩니다.
3. 기본 목록 또는 **새 목록**에 추가합니다. 목록에만 저장하거나 즉시 다운로드를 시작합니다.
4. **다운로드** 탭에서 전체 진행과 실패를 확인합니다. 알림에서도 일시정지할 수 있습니다.
5. 완료 항목의 **파일 열기**를 누릅니다. 파일은 휴대폰 **다운로드 → VideoDownloader**에 있습니다. 재생목록은 상세에서 개별 파일을 열거나 공유합니다.

일반 다운로드가 실패하면 상세의 **페이지 열기**를 누릅니다. 필요하면 로그인하고 영상을 직접 재생합니다. **찾은 미디어**에서 저장할 스트림을 선택하거나 **원래 주소 재시도**를 누릅니다. 사이트가 재생에 필요한 원본을 제공하지 않으면 저장되지 않을 수 있습니다.

설정에서 TXT/JSON 목록을 가져오거나 JSON으로 백업하고, 테마와 엔진 업데이트를 관리합니다. 일시정지·실패 항목은 이어받기/재시도로 다시 시도합니다. 일부 완료 항목은 이미 저장한 파일을 유지하며 남은 항목을 재시도합니다. 앱 강제 종료 후 자동 실행을 가장하지 않으며 앱을 열고 이어받기를 누릅니다.

## 실제 작업·연결 상태

Android 작업 원본은 현재 ChatGPT 작업 폴더의 `VideoDownloaderAndroid`이며 동일 소스를 통합 GitHub의 `video-downloader-android-20261006` 전용 브랜치에 보존합니다. 로컬 작업 제한으로 D 드라이브에 새 Android 프로그램을 설치하지 않았습니다. 기본 D:\A_KJ\AI 정책의 예외 이유는 허용된 작업 폴더에서 구현하고 GitHub 빌드 환경에서 APK를 만드는 현재 권한 제한입니다. 바탕화면에는 저장하지 않습니다.

통합소통방의 N-0001~N-0009와 기존 프로젝트 안내를 읽었습니다. 본인 기록의 작성과 기존 PC 소통함에 대한 배포·중앙 앱 수집은 구분합니다. 기존 PC 소통 폴더에 대한 쓰기·자동 수집은 확인되지 않았습니다. 실제 휴대폰 설치/사용과 모든 외부 사이트 성공은 자동 QA와 별도입니다.

## UI 개편 1.1.0

링크 추가 화면에서 주소를 입력한 뒤 **페이지 열기**로 앱 안에서 바로 이동할 수 있습니다. 목록에 저장하지 않고 페이지부터 볼 수 있고, 각 영상에서도 **페이지 열기**를 누릅니다. 브라우저 주소를 직접 바꾸거나 뒤로/앞으로 이동하고 페이지를 목록에 담을 수 있습니다.

저장 형식과 화질은 자동으로 처리하므로 기본 화면에 선택 옵션이 없습니다. 다운로드 도움말은 설정의 접힌 영역에서 확인합니다. 목록/팝업/선택에는 짧은 애니메이션을 적용하며 기기의 동작 줄이기를 존중합니다.

**삭제 방법 선택**에서 **목록에서만 삭제**하면 휴대폰 파일은 남습니다. **저장 파일 삭제**는 확인 후 선택한 항목의 실제 파일만 지우고 링크는 남깁니다. 진행 중인 영상은 먼저 일시정지해야 합니다. 파일 삭제 실패 시 실패 파일의 기록은 유지합니다.

이전 1.0.2 빌드는 서명키를 보존하지 않았습니다. 업데이트가 거절되면 기존 앱에서 설정 → 목록 백업 → 내보내기를 먼저 하고, 기존 앱 삭제 후 1.1.0을 설치해 백업을 가져오세요. 공개 다운로드 파일은 유지되지만 삭제/재설치 전 백업은 필요합니다. 이번 버전부터 빌드 서명키를 캐시합니다.

빌드·검증 완료 여부는 `task-ui-progress.json`과 해당 Actions 결과가 원본입니다. 실기기 Galaxy S22 테스트는 별도입니다.
