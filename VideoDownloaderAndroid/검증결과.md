# 영상다운로더 Android 1.0.2 검증

[빌드와 자동 검사 실행](https://github.com/kimjae134679/project-operations-hub/actions/runs/37476104820) · [검증 파일과 캡처](https://github.com/kimjae134679/project-operations-hub/tree/video-downloader-android-20261006/VideoDownloaderAndroid/dist/qa)

Android 앱은 링크를 직접 입력하고 이름 있는 목록에 모아 선택한 항목을 다운로드합니다. 영상 길이로 제외하지 않으며, 다운로드한 실제 파일을 휴대폰 다운로드 폴더에 저장한 뒤 완료로 표시합니다.

## 확인한 범위

| 검사 | 확인 내용 |
|---|---|
| 빌드 | Debug·Release와 ABI별 APK 생성, JVM URL 파서 검사, Android lint 실행 |
| 화면 자동 검사 | 360·412·800px에서 목록 생성, 링크 입력, 중복 처리, 검색, 필터, 선택 이동·삭제, 테마, 긴 한글·주소, 상세 닫기, 가로 넘침과 표시 버튼의 최소 44px 터치 높이 |
| 실제 Android 엔진 | Android 35 x86_64 에뮬레이터에 앱을 설치하고 로컬 HTTP 서버의 MP4·HLS·DASH를 yt-dlp/FFmpeg로 저장 |
| 짧은 영상 | 3초 영상 다운로드·저장 성공. 최소 길이 제한 없음 |
| 파일 저장 | MediaStore에 등록한 URI를 직접 열어 파일이 비어 있지 않은지 확인, 동명 파일 `_001` 처리 |
| 취소·이어받기 | 속도를 제한한 12초 MP4 다운로드를 실제 중단하고, 중단 중 삭제 방지·일시정지 상태·재시도 저장 완료 확인 |
| 복구 | 다운로드 중 상태를 재현해 Store.recover가 일시정지 항목으로 복구하는지 확인 |
| 시스템 메뉴 | WebView 화면 하단이 Android 시스템 내비게이션 영역보다 위에 있는지 네이티브 좌표 검사. 캡처에서 발견한 겹침을 FrameLayout inset 처리로 수정 |
| 패키지 | APK 서명 검증, 16KB 패키지 정렬 검사, SHA256 생성 |

실행 결과는 `dist/qa/native.txt`, `RESULT.txt`, 서명 검사 파일과 화면 캡처에 남깁니다. Lint 경고는 HTML 보고서에 보존합니다. 동기식 목록 저장은 복구 기록 보존을 위해 사용하며, Store는 Activity 대신 Application context를 보관합니다. 내부 UI와 사이트 재생·탐색에 필요한 JavaScript를 사용하고 외부 사이트에는 Android 명령 브리지를 노출하지 않습니다.

## 확인하지 않은 범위

실제 Galaxy S22 기기에 설치하거나 모든 외부 사이트를 시험한 결과는 아닙니다. 네이티브 검증은 x86_64 에뮬레이터이며 arm64-v8a와 armeabi-v7a 설치파일은 빌드·서명·패키지 검사까지 확인합니다. MP3와 모든 개별 코덱, 재생목록 전체, 외부 로그인·DRM 콘텐츠의 성공을 자동 검사 결과로 주장하지 않습니다.

앱에는 원본 포맷 재시도, 브라우저 미디어 발견과 사용자가 로그인한 뒤 재시도하는 기능을 포함했습니다. DRM, 접근 권한 부족, 만료된 주소와 사이트 차단으로 실패하는 영상은 원인을 표시합니다.
