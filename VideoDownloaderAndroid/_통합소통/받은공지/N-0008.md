# N-0008 · 각 프로젝트의 자료 위치와 사용 안내를 먼저 읽기

- 버전: 2
- 대상: 허브에 연결된 프로젝트의 모든 담당 AI
- 시행 근거: 2026-10-06 11:46 KST 사용자 최신 지시

## 사용자가 찾고 쓰는 안내는 프로젝트 안에

각 담당자는 실제 프로젝트 루트의 프로젝트_사용안내.md를 작성·유지합니다. 이미 충분한 TXT/Markdown 안내가 있다면 보존하고 이 진입 파일에서 연결합니다.

**어떤 일을 하는 프로젝트인지 → 무엇을 실행/열기/듣기 하면 되는지 → 실제 자료가 어디에 있는지**를 쉬운 한국어로 설명합니다. 입력·결과·참조·비교·이전·보관·복구·진행·개발 자료의 실제 위치와 역할을 빠뜨리지 않습니다. 자료가 없거나 연결되지 않았으면 미확인/없음/준비로 적습니다. 구체적 작성 기준은 허브 05_TEMPLATES/PROJECT_GUIDE.md입니다.

오디오북처럼 음원이 많은 프로젝트는 최신 전체 음성·새 제작 목록·장면별 음성·배역 비교·선호 기준·원본 표본·추가/미승인 표본·이전판 각각을 어디서 듣는지 안내합니다. 개별 WAV/MP3를 전부 나열하거나 중복 복사할 필요는 없습니다. 필요하면 실제 화면 이미지·기존 자료 그림도 연결하고 행동을 설명합니다.

## AI가 작업을 시작·재개할 때

현재 사용자 지시와 해당 로컬 안내를 먼저 읽고 실제 README/AGENTS·최신 인수인계·필요 파일로 좁혀 확인합니다. 안내가 없거나 오래됐으면 실제 자료를 조사해 보완합니다. 새 결과·경로·실행기·사용방법이 생기면 같은 작업에서 안내도 갱신합니다. 안내를 읽었다는 것만으로 앱 실행·재생·품질 승인·외부 서비스 성공까지 확인됐다고 쓰지 않습니다.

기존 사용자 지시와 프로젝트 규칙을 보존하며 실제 현재 파일·상태가 오래된 안내보다 우선합니다. 원본·모델·환경·미저장 작업을 설명을 위해 이동/삭제하지 않습니다. 비밀값·계정·개인정보·소설 원문·음원/영상/모델·비공개 검토 JSON을 공통 안내/공지로 복사하지 않습니다. 로컬 안내에는 자료 위치와 설명만 공유합니다.

## 공유와 확인 범위

프로젝트 로컬 안내와 허브의 사람용 폴더 지도는 연결하되 상세 설명의 원본은 각 실제 프로젝트에 둡니다. 전달·작성·앱 수집·중앙 공유·각 AI의 실제 읽음·적용을 구분합니다. 안내 창이나 공지가 생겼다고 다른 독립 채팅이 자동으로 깨어나 읽은 것은 아닙니다.

본인 공지 확인과 명령·실제 답변·검증·남은 일 기록만 작성합니다. 다른 담당자의 읽음·적용은 대신 체크하지 않습니다. 실제 연결이 없는 프로젝트는 연결 대기로 남깁니다.

기존 00_사용안내.md·00_사용안내.txt·README의 충분한 설명은 보존하고 프로젝트_사용안내.md에서 연결합니다. 관리 앱의 기본 안내 진입 파일은 프로젝트_사용안내.md입니다. 05_TEMPLATES/PROJECT_USER_GUIDE.md는 현재 PROJECT_GUIDE.md로 연결합니다. 같은 공지 r1의 서로 다른 안내 파일명 제안을 r2로 통합했으며 기존 확인 기록은 이력으로 보존합니다. 현재 r2 본문을 읽은 담당자만 새 확인을 작성합니다.
