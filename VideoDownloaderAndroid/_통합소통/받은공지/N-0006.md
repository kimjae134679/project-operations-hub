# N-0006 · 멀티의 신 서버 연결과 운영 구분

버전 1 · 2026-10-05 KST · 대상: 모든 AI, 특히 게임·서버·관제·소통 담당

## 게임 개발·배포·서버는 역할이 다릅니다

- 현재 게임 개발 원본은 `PhoneLoL_02-Source`, 공개 설치파일은 `PhoneLoL_02`, `PhoneLOL`은 과거 개발 이력입니다. 실제 PC 게임 Git 루트 `D:\A_KJ\AI\PhoneLoL_02`의 origin도 `PhoneLoL_02-Source`로 확인했습니다. 옛 안내·APK 폴더 이름만으로 최신 소스나 휴대폰 설치파일을 판단하지 않습니다.
- 실제 서버 루트는 `C:\Users\user\Documents\MultiGod\PhoneLOL_LocalRuntime`입니다. 게임 개발과 서버 운영은 같은 게임의 관련 기능이지만 루트가 다르므로 공지 대상도 `PhoneLOL`과 **`PhoneLOL-Server`**로 구분합니다. 서버가 추가돼 기본 필수 대상은 기존 13개에서 **14개**입니다. 실제 연결된 PC 진입점 수와 모든 공지 대상의 연결 상태는 같지 않습니다.
- 각 실제 루트의 `_통합소통`에 받은 공지·보낼 자료·본인 확인 기록을 연결합니다. 앱이 켜진 동안 검증·수집·중앙 동기화를 반복하며 담당자별 수동 업로드 의무는 없습니다. 배포·수집·공유를 읽음·적용과 구분하고 다른 AI나 클라이언트 담당자 기록을 서버 담당자의 확인으로 대신 체크하지 않습니다.

## 기본 관측은 읽기 전용입니다

- 서버 프로세스 식별과 같은 PC의 `127.0.0.1:29000` 온라인·정책 API를 기본 근거로 사용합니다. 접속·준비·플레이, 응답 시각·조회 실패를 구별하고 개인 계정 목록·키·명령 전체를 일반 화면이나 공유 자료에 넣지 않습니다. 실패나 누락을 0명으로 바꾸지 않고 집계의 전체·부분집합을 합산하지 않습니다.
- 기존 관리창 v38의 버튼 제어 대상은 v30인데 조사 당시 실제 서버는 v33이었습니다. 시작·종료·재시작 동작의 정합성을 확인하기 전에는 안전한 제어로 표시하거나 임의 실행하지 않습니다. 이번 관측에서는 원격 서버 코드 수정·서비스 재시작·DB 변경·배포를 하지 않았습니다.
- 운영 정책의 업데이트 안내와 게임 최신 버전, 파일 존재·실행·HTTP 응답·실제 플레이 완료를 구분합니다. 과거 조사 값은 참고이며 재개 시 최신 원본·실제 런타임을 다시 확인합니다.
