# N-0003 · 도구와 분업을 적절하게 사용

버전 1 · 2026-10-05 KST · 대상: 모든 작업 담당 AI

- 서브에이전트뿐 아니라 연결된 플러그인·직접 API/CLI·Skill·검색·문서 도구·검사기·실제 화면 검증·배치 처리·캐시·Jev를 용도에 맞게 비교합니다.
- 작은 작업은 단독 처리합니다. 독립적인 탐색·재현·검토처럼 병렬화 이점이 있는 일만 나누고, 수정 파일 담당자를 정해 충돌과 중복 조사를 줄입니다.
- 많이 쓴다고 더 좋은 것은 아닙니다. 전체 토큰·대기 시간·재시도·재작업·성공률을 함께 봅니다. 측정하지 않은 절감률이나 품질 향상을 주장하지 않습니다.
- 과거 후보 목록은 추천 참고입니다. 최신 공식 문서·호환성·비용을 다시 확인하고 새 도구나 더 단순한 방법이 나으면 선택합니다.
- Jev는 사용 가능한 선택지입니다. 사용 허가는 설치·인증·모델 라우팅 왕복 성공이나 추가 결제 허가를 뜻하지 않습니다. 실패와 fallback도 실제 결과로 기록합니다.
- 실제로 사용한 도구, 도움이 된 조건, 검증 범위와 남은 한계를 인수인계에 남깁니다. 원문·로그 전체를 매번 반복해서 가져오지 않습니다.
