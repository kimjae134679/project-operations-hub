# N-0001 · 공지 확인과 기록

버전 2 · 2026-10-05 KST · 대상: 허브에 연결된 모든 프로젝트와 담당 AI

## 바뀐 점

각 AI가 GitHub에 따로 업로드해야 한다는 이전 절차를 바꿉니다. **본인은 프로젝트의 소통 폴더에 기록하고, 관리 앱이 수집해 중앙에 동기화합니다.** 버전 1의 확인 기록은 보존하지만 이번 변경을 읽은 기록으로 세지 않습니다.

## 해야 할 일

- 작업 시작·재개·인수인계 시 `_통합소통/받은공지/manifest.json`과 본인 확인 기록을 비교합니다. 새·변경 공지 본문을 실제로 읽습니다. 받은 공지가 최신 동기화됐는지도 확인합니다.
- 본인의 프로젝트 ID, AI 식별자, 세션, 공지 ID·버전·내용 해시, 확인 시간과 적용 내용을 `_통합소통/확인기록`에 기록합니다. 다른 AI가 읽었다고 대신 체크하지 않습니다.
- 읽었다는 기록과 적용 완료를 구분합니다. 적용 전이면 `읽음·적용 대기`, 적용했다면 근거, 해당 없으면 이유, 막혔으면 조건을 남깁니다.
- 적용 대기·막힘은 다음 인수인계에 남깁니다. 해결 후 본인 기록을 갱신합니다. 앱이 받은 기록의 형식·공지 버전·해시를 확인해 수집하고 중앙 확인 현황에 반영합니다.
- 공지 내용이 바뀌면 재확인합니다. 이전 버전·다른 해시 기록을 최신 확인으로 취급하지 않습니다.
- 본인 기록을 만들었다는 것과 앱이 수집했다는 것, 중앙에 공유됐다는 것은 별개입니다. 앱 종료·인증 문제·오프라인으로 공유가 남았으면 **동기화 대기**로 남깁니다. 각 담당자에게 별도 GitHub 수동 업로드를 완료 조건으로 강제하지 않습니다.

## 효율과 범위

목록과 본인 기록부터 확인하고 이미 읽은 같은 내용은 반복 로딩하지 않습니다. 자동 폴더 생성·공지 배포는 읽음이나 적용 완료가 아닙니다. 최신 사용자 지시·실제 프로젝트 규칙·수정 권한이 우선이며, 다른 독립 채팅의 확인은 실제 본인 기록으로만 판단합니다.
