# AGENTS.md

## Goal
Describe the product or task this repository exists to complete.

## Authorized without re-asking
- Read and edit local project files.
- Build, lint, format, and run local tests.
- Perform non-destructive debugging and inspect logs.

## Ask before
- Destructive deletion or irreversible migration.
- Production deployment or production-data modification.
- Spending money or enabling paid services.
- Account, permission, credential, or external-message changes.

## Completion
DONE means every explicit requirement is satisfied and the applicable build/tests pass.
The agent's own completion statement is not evidence.
If a local, authorized check fails, fix it and re-run the check instead of stopping after the first implementation.

## Simplicity
Prefer the smallest complete change. Reuse existing code and native capabilities first.
Do not simplify by removing requested behavior.
