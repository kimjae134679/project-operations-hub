# Astra Codex Workbench

Codex/GPT-6 Astra를 장시간 개발 작업에 쓰기 위한 작은 스타터 저장소입니다.
핵심은 지시를 많이 붙이는 것이 아니라 **권한은 명확하게, 구현은 단순하게, 완료 판정은 엄격하게** 만드는 것입니다.

## 구성

- `AGENTS.md` — 에이전트의 상시 작업 규칙
- `docs/ACCEPTANCE.md` — 완료 판정 기준
- `skills/ponytail-lite/SKILL.md` — 과잉 구현을 줄이는 최소 구현 규칙
- `templates/AGENTS.template.md` — 다른 프로젝트에 복사할 템플릿
- `scripts/self-check.ps1` — 이 스타터 자체 검증

## 기본 원칙

1. 로컬 읽기·수정·빌드·테스트·비파괴적 디버깅은 중간 승인 없이 계속합니다.
2. 삭제·외부 배포·비용 발생·계정/권한 변경 같은 위험 행동은 별도 승인을 받습니다.
3. 요구사항은 줄이지 않습니다. 구현 방식만 가능한 한 단순하게 만듭니다.
4. 에이전트의 “완료했습니다”는 증거가 아닙니다.
5. 실제 빌드/테스트/요구사항 대조가 모두 통과해야 DONE으로 봅니다.

## 사용법

새 프로젝트를 시작할 때 `AGENTS.md` 또는 `templates/AGENTS.template.md`를 프로젝트 루트에 두고,
프로젝트별 빌드·테스트 명령과 금지 범위만 채우면 됩니다.
