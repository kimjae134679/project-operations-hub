# Project Operations Hub

여러 프로젝트를 한곳에서 **운영·연결·검증·협업·지식 재사용**하기 위한 통합 관리 허브입니다.

## 사용자는 여기부터

**평소에는 아래 폴더만 보면 됩니다.**

### [`000_사용자용/`](000_사용자용/)

- [프로젝트 현황](000_사용자용/01_프로젝트_현황.md)
- [설치·사용 도구 현황](000_사용자용/02_설치_도구_현황.md)
- [후보 도구 요약 및 설치 무게](000_사용자용/03_후보_도구_요약.md)
- [소통창구](000_사용자용/04_소통창구.md)
- [내가 정한 공통 작업 규칙](000_사용자용/05_내_작업규칙.md)
- [AI 도구·플러그인 사용 구분](000_사용자용/06_AI_도구_플러그인_사용구분.md) — 지금 바로 쓸 수 있는지, AI 혼자 가능한지, 내가 도와줘야 하는지, 얼마나 무거운지

`000_사용자용/`은 **사용자가 직접 읽는 내용만 한글로 요약**합니다. 제품명·저장소명·경로처럼 원문이 필요한 고유명사만 영어를 유지합니다.

## 나머지는 AI/내부 관리 영역

사용자가 특별히 원문을 확인할 때만 보면 됩니다.

| 내부 구역 | 역할 |
|---|---|
| `00_SYSTEM/` | 허브 구조·문서·상태 모델 |
| `01_CONTROL/` | 정책·도구·프로젝트·설치 위치의 내부 원본 |
| `02_PROJECTS/` | 프로젝트별 실제 연결 정보 |
| `03_KNOWLEDGE/` | 후보 도구 상세 조사·검증 패턴·경험 |
| `04_COMMUNICATION/` | 프로젝트/AI 간 실제 게시글·스레드·우편함 |
| `05_TEMPLATES/` | 새 프로젝트·인수인계·대화용 템플릿 |
| `99_ARCHIVE/` | 과거 문서와 종료 기록 |
| `AGENTS.md` | AI 실행 규칙과 읽기 순서 |

## 내부 구조

```text
Project Operations Hub
├─ 000_사용자용/          ← 사용자가 읽는 한글 요약
├─ 00_SYSTEM/             ← AI/내부
├─ 01_CONTROL/            ← AI/내부 원본
├─ 02_PROJECTS/           ← 프로젝트 연결
├─ 03_KNOWLEDGE/          ← 상세 조사
├─ 04_COMMUNICATION/      ← 실제 대화 기록
├─ 05_TEMPLATES/          ← 템플릿
├─ 99_ARCHIVE/            ← 과거 자료
├─ AGENTS.md              ← AI용
└─ README.md              ← 지금 이 안내
```
