# Project Operations Hub

현재 ChatGPT 프로젝트에서 여러 작업을 **연결·검증·인수인계**하기 위한 전체 컨트롤러입니다.

이 저장소의 규칙은 현재 프로젝트 범위에만 적용합니다. 실제 코드와 최신 실행 상태는 각 프로젝트 저장소가 원본이며, 이 허브는 정책·포인터·도구 상태·소통 기록을 관리합니다.

## 저장소 구조

| 구역 | 역할 |
|---|---|
| `000_사용자용/` | 사용자가 보는 한글 요약 |
| `00_SYSTEM/` | 컨트롤러·문서·상태 모델 |
| `01_CONTROL/` | 정책·프로젝트·도구·설치 위치 원본 |
| `02_PROJECTS/` | 실제 프로젝트 저장소로 가는 포인터 |
| `03_KNOWLEDGE/` | 후보 도구 조사와 재사용 지식 |
| `04_COMMUNICATION/` | 주제별 진행 기록과 AI 우편함 |
| `05_TEMPLATES/` | 프로젝트·인수인계·대화 템플릿 |
| `99_ARCHIVE/` | 종료되거나 교체된 자료 |

## 원본 구분

- 실제 프로젝트의 코드·버전·최신 상태 → 해당 프로젝트 저장소
- 공통 정책과 등록 상태 → 이 허브의 `01_CONTROL/`
- 과거 진행 과정 → `04_COMMUNICATION/`
- 사용자가 확인할 현재 요약 → `000_사용자용/`

허브 요약과 실제 저장소가 다르면 실제 저장소의 현재 상태를 우선합니다. 내부 원본을 바꾸면 대응되는 사용자용 문서도 함께 갱신합니다.
