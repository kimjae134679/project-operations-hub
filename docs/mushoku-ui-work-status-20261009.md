## 통합 담당이 참고할 계약

UI는 제작 담당이 관리하는 canonical 등록을 읽는다. 완성본 조건과 chapter+SHA 별칭 통합을 적용하며 보관본/부분본을 현재 완성본으로 승격하지 않는다. 본문은 음원 버전 SHA에 연결한다. 목록 갱신은 메뉴에 반영하지만 재생 중 음원을 자동 교체하지 않는다. UI가 production 승인이나 제작 상태를 작성하지 않는다.

기존 `mushoku_audiobook_hub_v1`의 위치·속도·화면·스크롤과 `mushoku_voice_asset_viewer_v1`의 평가·분류·메모·들은 표시·버전 이력을 보존한다. 화자 변경은 원본 표본에만 있으며 개별/일괄 지정, 불일치와 폐기의 독립 상태, 다음 탐색에서 폐기 반영을 유지한다. 상세 사용자 평가와 원문·음원은 공유 문서에 복제하지 않는다.

기존 본문 디자인을 복원했고 두 모드, 회차 제목 `N화 · 원래 제목`, 독립 상단 평가 진입, 핵심 저장·재생·스크롤·일괄 조작은 격리된 유한 렌더에서 검수했다. [검수 도구](https://github.com/kimjae134679/Mushoku-Tensei-AI-Audiobook/blob/6e03980e0c8e97e67953936307ecb94d505d3c66/tests/verify_unified_renderer.py)는 설치 소스와 제한된 기존 음원을 사용하는 독립 Edge about:blank 검수다. 실제 사용자 탭을 강제 새로고침하거나 종료하지 않았다. 두 모드 스크린샷과 receipt는 프로젝트 로컬 output에 보존하며 GitHub에 게시하지 않는다.

누적 제한은 프로젝트 보고서에 보존했다: file: 정책 차단, Library 소비 경로/HTTP 403, 기본 exec helper 실패와 허용된 공식 실행 경로, DesktopCommander 한도, 과거 부모 메시지 전송과 공용 ACK의 자동 승인 검토 거절. 두 거절 작업은 재시도하거나 우회하지 않았다. 이번 기록 초안의 스키마 오류는 형식 수정 후 공식 검증을 통과했다.

통합 화면 157화 진단은 전체본·짧은 파일과 별칭의 SHA/URL을 구분한 읽기 근거만 기록한다. 실제 탭 속도와 음질 변화 원인·해결·제작 승인 상태는 확정하지 않는다. 제작 담당의 후속 구간 대조를 이 문서 완료와 혼동하지 않는다.

이 문서는 공통 계약에 필요한 안전한 기술 요약이다. 원문 사용자 명령/답변 task_exchange 전체, 소설 원문, 음원, 상세 평가, 비밀정보와 사적 추론은 게시하지 않는다. 안정 포인터인 `02_PROJECTS/Mushoku-Audiobook/README.md`나 공용 THREAD를 수정하지 않았다.
