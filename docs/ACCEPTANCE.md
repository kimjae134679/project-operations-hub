# Acceptance Gate

에이전트가 스스로 DONE이라고 말하는 것과 실제 완료를 분리합니다.

## 상태

`ASSIGNED -> EXEC -> CLAIMED -> GATED -> ACCEPTED`

- `CLAIMED`: 구현자가 완료했다고 주장한 상태
- `GATED`: 실제 검증 중인 상태
- `ACCEPTED`: 검증 조건을 통과한 상태

## 공통 검증

- [ ] 사용자가 요구한 항목이 빠짐없이 구현됨
- [ ] 관련 빌드 또는 실행이 성공함
- [ ] 핵심 사용 흐름을 직접 검증함
- [ ] 변경 범위에 맞는 테스트를 통과함
- [ ] 기존 기능의 명백한 회귀가 없음
- [ ] 임시 코드, 가짜 성공 처리, 미완성 placeholder가 없음
- [ ] 외부 요인 때문에 검증 못 한 부분은 명확히 표시함

## UI 작업 추가 검증

- [ ] 첫 화면에서 핵심 기능을 찾기 쉬움
- [ ] 반복 사용 동선이 불필요하게 길지 않음
- [ ] 작은 화면/큰 화면에서 주요 요소가 잘리지 않음
- [ ] 중복 버튼, 중복 정보, 과도한 설명이 없음

체크되지 않은 필수 항목이 있으면 ACCEPTED가 아닙니다.
