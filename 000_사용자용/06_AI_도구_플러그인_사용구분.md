# AI 도구·플러그인 사용 구분

이 문서는 **무엇을 지금 바로 쓸 수 있는지, 내가 도와줘야 하는지, AI가 알아서 처리할 수 있는지, 설치가 얼마나 무거운지**를 사용자 기준으로 빠르게 보기 위한 문서입니다.

## 표기

- `바로 사용` — 새 설치 없이 현재 ChatGPT/연결 도구에서 사용 가능
- `연결 필요` — Plugin/OAuth 연결 정도만 필요
- `AI 설치 가능` — 관리자 승인·로그인 같은 막힘이 없으면 AI가 PC에서 설치·설정 가능
- `사용자 1회 도움` — 로그인, OAuth, UAC, API key, 2FA, 결제 등의 순간만 사용자가 필요
- `사용자 직접 사용` — 설치 후 GUI나 앱을 사용자가 직접 쓰는 비중이 큼

설치 부담은 `⚪ 없음 / 🟢 가벼움 / 🟡 보통 / 🟠 무거움 / 🔴 매우 무거움`으로 표시합니다.

## 지금 바로 활용 가능한 것

| 도구 | 주로 누가 씀 | 도움 | 부담 | 용도 |
|---|---|---|---|---|
| GitHub | 둘 다 | 대부분 없음 | ⚪ | 저장소 수정, 문서, PR, 이슈, Actions |
| ChatGPT Files / Library | 둘 다 | 없음 | ⚪ | 올린 파일·라이브러리 자료 검색/읽기 |
| Gmail | 둘 다 | 계정 권한 필요 시 1회 | ⚪ | 메일 검색/읽기/작성 |
| Google Calendar | 둘 다 | 계정 권한 필요 시 1회 | ⚪ | 일정 조회·생성·수정 |
| Google Drive | 둘 다 | 계정 권한 필요 시 1회 | ⚪ | Drive/Docs/Sheets/Slides |
| Notion | 둘 다 | 계정 권한 필요 시 1회 | ⚪ | 문서·DB·업무 정리 |

즉 이런 것들은 별도 대형 프로그램을 새로 깔지 않아도 AI가 바로 활용하기 쉬운 축입니다.

## ChatGPT 안에서 추가 연결해볼 만한 플러그인 후보

현재 Plugin Directory에서 확인한 것 중 우리 작업과 연결점이 있는 것들입니다. **아직 필요도 없이 전부 설치하지는 않습니다.**

### 개발
- `Figma` — 디자인→코드 작업
- `Codex Security` — 코드 보안 점검
- `Superpowers` — 계획·개발·디버깅 보조
- `OpenAI Library` — Codex에서 ChatGPT Library 활용
- `Airtable` — 구조화 데이터 관리

### 콘텐츠/영상
- `Canva` — 디자인 제작·편집
- `HeyGen` — AI 영상·아바타
- `HyperFrames by HeyGen` — HTML 기반 영상 렌더
- `Remotion` — 코드 기반 영상 생성

### 주식/리서치
- `Longbridge` — 주가/금융 데이터
- `Quartr` — 기업 리서치 자료
- `Financial Datasets` — 시장 데이터
- `Stocktwits` — 투자자 커뮤니티 데이터
- `Bigdata.com` — 금융 뉴스·리서치·데이터
- `Consensus` — 과학 논문 검색
- `Sider Scholar` — 논문 검색·저장·대화

이 계열은 대부분 **PC에 무거운 프로그램을 설치하는 방식이 아니라 ChatGPT에서 Plugin 연결**하는 쪽입니다. 대신 서비스에 따라 로그인/OAuth가 필요할 수 있습니다.

## AI가 알아서 설치·설정하기 쉬운 것

아래는 PC가 연결되어 있고 관리자 승인이나 계정 로그인이 필요하지 않다면 AI가 직접 진행하기 쉬운 계열입니다.

- 단일 npm/pip/CLI 도구
- MarkItDown 같은 경량 변환 도구
- Vercel Skills 같은 Skill 검색·설치 도구
- 프로젝트 내부에만 넣는 Skill/스크립트
- GitHub 기반 경량 Agent 보조도구

막히는 순간이 UAC·OAuth·2FA·API key 발급이라면 그때만 내가 한 번 도와주면 됩니다.

## 내가 직접 써야 하는 비중이 큰 것

- `ComfyUI` — 노드 GUI를 직접 만지거나 결과를 보면서 조정하는 비중이 큼
- `Blender` — 자동화 가능하지만 최종 모델 확인·수정은 직접 보는 편이 좋음
- `Canva`, `Figma` — AI가 작업해도 최종 디자인 검수는 직접 하는 가치가 큼
- `Dify`, `Langflow`, `Open WebUI`, `LobeHub` — 플랫폼 자체 UI를 사용자가 직접 쓸 수 있는 유형

---

## 무거운 것은 따로 본다

### 🔴 매우 무거움
- `ComfyUI` — 모델, LoRA, VAE, PyTorch/CUDA, VRAM, 디스크가 크게 늘어남
- `vLLM` — 고성능 LLM 서버용. GPU/CUDA/모델 부담 큼
- `RAGFlow self-host` — RAM·디스크·Docker·여러 서비스 필요
- 대형 `DeepSeek`/로컬 LLM — 모델에 따라 수십 GB 이상 가능

### 🟠 무거움
- `Ollama` — 프로그램은 간단하지만 로컬 모델 파일이 무거움
- `Dify self-host` — 직접 서버 운영 시 Docker/DB 관리 필요
- `Firecrawl self-host` — 직접 브라우저·크롤링 인프라까지 운영하면 무거움

이런 것은 `괜찮아 보이니 일단 설치` 식으로 다루지 않습니다.
