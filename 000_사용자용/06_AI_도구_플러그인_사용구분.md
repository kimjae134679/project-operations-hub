# AI 도구·플러그인 사용 구분

이 문서는 **무엇을 지금 바로 쓸 수 있는지, AI가 혼자 끝까지 다룰 수 있는지, 내가 도와줘야 하는지, 무료인지, 설치가 얼마나 무거운지**를 사용자 기준으로 빠르게 보기 위한 문서입니다.

## 표기

### AI가 혼자 다룰 수 있는 정도
- `AI 단독 가능` — 필요한 입력만 있으면 AI가 기능을 처음부터 끝까지 처리 가능
- `1회 준비 후 가능` — 로그인/OAuth/UAC/API key 같은 준비만 내가 한 번 해주면 이후 대부분 AI가 처리 가능
- `부분 가능` — AI가 많이 처리할 수 있지만 GUI 선택·시각 확인·수동 단계가 자주 필요
- `사용자 중심` — 핵심 사용은 내가 직접 해야 함
- `미확인` — 실제 운용성 검증 전

### 비용
- `무료` — 완전 무료/오픈소스로 자체 사용 가능
- `무료 플랜` — 기간 제한 없는 무료 구간이 있으나 사용량 제한 가능
- `기존 요금제 포함` — 내가 이미 쓰는 서비스 안에서 추가 결제 없이 사용
- `무료체험` — 기간/크레딧 제한 체험
- `유료` — 추가 결제 필요
- `미확인` — 공식 가격을 아직 확인하지 못함

### 설치 부담
`⚪ 없음 / 🟢 가벼움 / 🟡 보통 / 🟠 무거움 / 🔴 매우 무거움`

## 내 기본 선택 기준

**유료 도구는 기본적으로 제외합니다.** 내가 따로 요청할 때만 봅니다.

**무료체험도 웬만하면 사용하지 않습니다.** 무료체험만 가능한 서비스보다 완전 무료·오픈소스나 기간 제한 없는 무료 플랜을 먼저 찾습니다.

우선순위는 대체로:

`무료·오픈소스 → 무료 플랜 → 기존 요금제 포함 → 무료체험 → 유료`

카드 등록이 필요하거나 체험 종료 후 자동결제되는 것은 무료처럼 취급하지 않습니다. 가격을 모르겠으면 `미확인`으로 두고 추천 우선순위를 낮춥니다.

## AI가 혼자 다루기 좋은 계열

다음 조건이면 내가 거의 안 건드리고 AI가 설치·설정·실사용까지 이어가기 좋습니다.

- 단일 npm/pip/uv/CLI 도구
- 프로젝트 내부에만 넣는 Skill/스크립트
- API/MCP/Plugin으로 기능이 직접 노출되는 도구
- MarkItDown 같은 경량 변환 도구
- Vercel Skills 같은 Skill 관리 CLI
- 로그인·유료결제·2FA·CAPTCHA가 필요 없는 GitHub 기반 도구

**중요:** 설치만 AI가 할 수 있는 것과, 실제 기능까지 AI가 혼자 운용할 수 있는 것은 다르게 표시합니다.

---

## 내가 직접 써야 하는 비중이 큰 것

- `ComfyUI` — 설치/실행 자동화는 가능해도 노드 그래프와 생성 결과를 계속 보고 고르는 사용이 많아서 `부분 가능~사용자 중심`
- `Blender` — 자동화 가능하지만 최종 형태·비율·재질 확인은 내가 보는 편이 좋음
- `Canva`, `Figma` — AI가 작업해도 최종 디자인 선택은 직접 하는 가치가 큼
- `Dify`, `Langflow`, `Open WebUI`, `LobeHub` — 플랫폼 UI 자체를 내가 직접 운영할 수 있는 유형

---

## 무거운 것은 따로 본다

### 🔴 매우 무거움
- `ComfyUI` — 모델, LoRA, VAE, PyTorch/CUDA, VRAM, 디스크가 크게 늘어남
- `vLLM` — 고성능 LLM 서버용. GPU/CUDA/모델 부담 큼
- `RAGFlow self-host` — RAM·디스크·Docker·여러 서비스 필요
- 대형 `DeepSeek`/로컬 LLM — 모델에 따라 수십 GB 이상 가능

### 🟠 무거움
- `Ollama` — 프로그램은 간단하지만 로컬 모델 파일이 무거움
- `Dify self-host` — 직접 서버 운영 시 Docker/DB 관리 필요
- `Firecrawl self-host` — 직접 브라우저·크롤링 인프라까지 운영하면 무거움

이런 것은 `괜찮아 보이니 일단 설치` 식으로 다루지 않습니다.

## 앞으로 새 도구는 이렇게 정리

새 도구가 보이면 다음을 같이 적습니다.

`지금 바로 쓸 수 있는가 → AI가 기능을 혼자 끝까지 다룰 수 있는가 → 설치만 혼자 가능한가 → 내가 1회 도와줘야 하는가 → 내가 직접 써야 하는가 → 무료/무료 플랜/기존 요금제/무료체험/유료/미확인 → 설치됐는가 → 실제 채택됐는가 → 얼마나 무거운가 → 비용·권한·보안 주의점`

같은 도구가 SNS나 GitHub 목록에 여러 번 나와도 중복으로 쌓지 않고 기존 항목을 갱신합니다.
