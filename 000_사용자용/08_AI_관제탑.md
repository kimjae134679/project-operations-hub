# 컨트롤타워 사용법

여러 프로젝트의 **프로그램과 자료를 한곳에서 찾고**, 용도를 확인한 뒤 열기·실행·중지하는 Windows 관리 앱입니다. 현재 설치본은 **0.7.0**입니다. 프로젝트·프로그램·자료 수는 실제 폴더 자동 발견에 따라 바뀌며, 문서·폴더·설치파일도 포함하므로 모두 실행 프로그램인 것은 아닙니다.

화면 왼쪽의 세로 메뉴에서 작업 공간을 바꿉니다. 프로젝트·프로그램 목록 위에서 마우스 휠로 이동할 수 있습니다. 큰 창은 프로그램 카드 두 열, 작은 창은 한 열로 표시합니다.

## 0.7.0에서 바뀐 사용법

초록색 중심 화면과 입체 버튼을 중립색·단순 버튼으로 바꿨습니다. 프로젝트 이름을 전부 보이고 각 프로젝트의 **사용 안내 읽기**에서 음원·소리·작업·결과·보관 자료 위치와 설명을 읽습니다. 안내 원본은 실제 프로젝트 안의 프로젝트_사용안내.md입니다.

**소통방**은 제목을 고르고 게시글처럼 읽습니다. **본문 넓게**로 목록을 접고 읽을 수 있습니다. 받은 요청·AI 답변·한 일·검증·다음 일은 사람이 읽는 본문이고, 원래 JSON은 **원본·AI 기록 보기**에 있습니다.

**도구·연결**에 원격 연결·Jev를 포함한 11개 도구가 표시됩니다. 이름·하는 일로 검색합니다. VoiceStudio·Zonos2의 안내에는 실행기·음성/배역/모델의 실제 위치와 미확인 조건을 구분했습니다.

서버의 **자동 갱신**은1/3/5/10초, **회전 속도**는빠르게/보통/천천히로 고릅니다. 기본3초·한바퀴1.4초입니다. 자동조회마다 아이콘을 돌리지 않으며 **지금 확인**을 누르면 부드럽게 한바퀴를 마칩니다.

[이번 검증 기록](../ai-control-tower/docs/READING-TOOLS-20261006.md)

## 내 프로젝트

1. 왼쪽에서 프로젝트를 선택합니다. 이름과 설명으로 하는 일을 확인하고, 검색으로 찾을 수 있습니다.
2. 가운데에서 필요한 프로그램이나 자료를 선택합니다. 기능별로 나뉘어 있으며 항목 검색도 가능합니다.
3. 오른쪽에서 무엇인지와 할 일을 확인합니다. 제작 화면은 열고, 휴대폰 설치파일은 위치를 보고, 음성 결과는 폴더에서 골라 듣습니다.
4. 실행한 작업은 중지하거나 **작업 기록**을 펼쳐 결과를 확인합니다. 폴더 위치와 자세한 기록은 필요할 때만 펼칩니다.

설명과 연결을 등록한 주요 프로젝트는 **멀티의 신, 무직전생 오디오북, 영상·음원 저장, 전체 프로젝트 관리, 주식 자동매매, 청약 도구**입니다. 추가 발견 항목은 용도를 확인하기 전까지 후보로 구분합니다. 게임의 이전 개발본·실험 사본·복구 자료와 오디오북 코드 보관본은 주 작업과 구분합니다. 각각 어디서 무엇을 하는지는 [프로젝트와 폴더 안내](11_프로젝트와_폴더_안내.md)를 봅니다.

게임의 최근 작업용 APK와 사용자 확인 완료본을 구분하며, APK를 PC 게임 실행파일로 표시하지 않습니다. 주식·청약은 조사 당시 빈 준비 폴더로 실행 기능이 없습니다. Unity 편집기와 기존 열기 스크립트를 확인해 `Unity로 열기`를 연결했습니다. 편집기 실행 자체는 이번 검증에서 수행하지 않았습니다.

## 도구·연결

- **프로젝트 폴더**: 기본 관리 루트는 `D:\A_KJ\AI`입니다. 오디오북과 다운로드 도구는 기존 `D:\AI`의 실제 폴더를 연결해 사용합니다. 자료를 한곳으로 옮길 필요는 없습니다.
- **작업에 필요한 연결**: 공유 원격 연결과 AI 작업에 필요한 도구 상태를 확인합니다. 자세한 기술 결과는 펼쳐 봅니다.
- **자동 시작 정리**: 공유 원격 연결의 중복 시작 등록을 백업 후 하나로 정리합니다. 현재 연결을 재사용하며 앱을 닫아도 공유 연결을 끄지 않습니다.
- **AI 작업 전달**: Jev를 선택해서 사용할 수 있습니다. 설치·허가·실제 실행 검증은 [Jev 현재 상태](07_Jev_현재상태.md)에서 구분합니다.
- **앱 관리**: 설치·자동 시작, 공유 연결 복구, 앱 제거와 화면 전환 효과 줄이기를 관리합니다.

관제탑이 시작한 작업과 자식 프로세스만 중지합니다. 같은 프로젝트 작업은 겹치지 않고 다른 프로젝트는 최대 3개까지 처리합니다. 앱 밖에서 이미 실행한 프로그램까지 자동으로 소유하거나 중지하지 않습니다.

## 공지사항·프로젝트 소통

**공지사항**에서 내용과 실제 확인 기록을 보고, **프로젝트 소통**에서 전달 여부·확인·적용·수집 자료를 따로 확인합니다. 각 프로젝트의 `_통합소통/보낼자료`에 짧은 안내·인수인계를 남기고, AI는 받은 공지를 실제 읽은 뒤 본인 확인 기록을 남깁니다. 앱이 켜져 있으면 로컬은 15초, 중앙은 1분 간격으로 처리하므로 담당자별 GitHub 수동 업로드가 필요 없습니다. 앱 종료·오프라인·인증 대기는 다음 연결에서 이어갑니다.

소통 폴더의 README에 있는 현재 기록 도우미 명령을 사용합니다. 보호된 로컬 도우미를 갱신할 수 없으면 기존 파일을 유지하고 중앙 도우미를 연결합니다. 실제 연결 루트 5개와 공지 필수 대상 14개는 다른 수이며, 미연결·미확인 대상은 대기로 보입니다. [공지와 자료 사용법](12_공지사항.md)

## 멀티의 신 서버

현재 접속·준비·플레이 인원, 모드별 집계와 응답 시각을 봅니다. **실행 폴더 보기**, **소통 폴더 보기**, **개발 코드**, **배포·설치파일**로 목적에 맞게 이동합니다. 개발 원본은 `PhoneLoL_02-Source`, 설치파일은 `PhoneLoL_02`이며 서버 루트는 게임 개발 폴더와 별개입니다.

집계 상태가 바뀔 때 서버 요약을 자동 수집합니다. 조회 실패를 0명으로 바꾸지 않습니다. 기존 관리창의 제어 대상 v30과 실제 서버 v33이 달라 시작·종료·재시작은 아직 연결하지 않았습니다. [서버 연결 안내](../ai-control-tower/docs/MULTIPLAYER_SERVER.md)

## 실제 위치와 확인 범위

- 앱: `D:\A_KJ\AI\Applications\AIControlTower\AIControlTower.exe`
- 코드·연결 목록: `D:\A_KJ\AI\Projects\project-operations-hub`
- 기존 설정·작업 기록·백업: `%LocalAppData%\AIControlTower`

연결된 프로그램·자료의 사람용 이름과 용도는 `project.catalog.json`에서 관리합니다. 개별 프로젝트의 기능과 실행 명령은 `project.control.json`으로 등록할 수 있습니다. 새로 발견한 폴더는 목적을 확인하기 전까지 후보이며, 발견만으로 설치·정상 실행·외부 연결까지 완료됐다고 표시하지 않습니다.

실제 테스트·화면 확인과 미검증 범위는 [0.4.1 표면 디자인·실행 검증](../ai-control-tower/docs/MATERIAL-DESIGN-20261005.md)에 있습니다. [개발·등록 방법](../ai-control-tower/README.md) · [이번 디자인 참고](../ai-control-tower/docs/DESIGN-REFRESH-20261005.md)

## 화면 선택

상단에서 **어두운 화면 / 밝은 화면**을 전환합니다. 선택은 다음 실행에도 유지됩니다. 기본은 밝은 화면입니다. 내 프로젝트에서 전체 이름과 기능별 펼침 목록으로 무엇을 열지 선택합니다. 공지·소통·서버·AI 작업 전달 창도 같은 화면 설정을 사용합니다.
