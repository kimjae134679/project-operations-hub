# AI 관제탑 (AI Control Tower)

Windows PC에서 Desktop Commander, Jev, Codex, GitHub CLI, n8n, AI Ops Runner의 실제 상태를 한 곳에서 확인하는 프로그램입니다.

- 실행 파일: `ai-control-tower\artifacts\win-x64\AIControlTower.exe`
- 상태는 5초마다 자동으로 갱신됩니다.
- 확인할 수 없는 상태는 성공으로 추측하지 않고 `Unknown`으로 표시합니다.
- 비밀번호, API 키, 토큰 값은 보여 주거나 기록하지 않습니다.
- 화면은 화이트·블루 대시보드와 어두운 실시간 작업 콘솔 형태로 표시됩니다.
- Jev 작업 버튼과 TXT 작업 큐는 현재 **비활성**입니다. 사용자 OpenAI/ChatGPT 계정의 토큰·사용량이 로컬 Jev 경로에서 소비되지 않도록 차단한 상태입니다.
- 설치를 누르면 기본적으로 `C:\Program Files\_My\AI\Applications\AIControlTower`에 설치하며, 권한이 없으면 LocalAppData를 사용합니다.
- Desktop Commander의 기존 표시형 자동 시작은 설치 전에 백업하고, 필요하면 관제탑의 복구 버튼으로 되돌릴 수 있습니다.

자세한 설치·복구·검증 방법은 [`ai-control-tower/README.md`](../ai-control-tower/README.md)를 참고하세요.
