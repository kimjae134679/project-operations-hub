# Jev 현재 상태

2026-10-05 확인. 사용자는 Jev 사용을 허용했습니다. **작업에 도움이 될 때 선택 사용하며, 매번 실행하거나 추가 결제하라는 뜻이 아닙니다.**

- 실제 설치: `jev-router 0.2.0`, `C:\Users\user\AppData\Roaming\npm`.
- 실제 upstream: [gargpratyush/jev-router](https://github.com/gargpratyush/jev-router). 현재 upstream 버전과 설치본은 다를 수 있습니다.
- 확인: Windows 사용자 환경에 Jev 키 설정 존재, Codex는 ChatGPT로 로그인됨. 값은 표시·기록하지 않았습니다.
- 미확인: 키 유효성, 실제 라우팅 왕복, 업무 완료, 비용/한도. 키 존재만으로 무료·정상 인증·과금 없음을 주장하지 않습니다.
- 컨트롤타워: 설정에서 선택 사용 가능. 기존 텍스트 큐는 자동 실행하지 않습니다. 명령·프롬프트는 CMD 문자열 연결 없이 전달하고 프로젝트별 실행 잠금·취소·시간 제한·로그를 사용합니다.
- 용도: 모델 라우팅. 프로젝트 발견·등록·실행 관리·검증·전달을 Jev 하나가 모두 해주는 것으로 설명하지 않습니다.
- 비교: 직접 Codex와 같은 완료 조건에서 시간·품질·재시도·전체 사용량을 비교합니다. 라우팅 지연·캐시 손실로 오히려 비효율적일 수도 있습니다.
