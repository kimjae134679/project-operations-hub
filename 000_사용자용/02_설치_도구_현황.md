# 설치·사용 도구 현황

여기서는 **후보가 아니라 실제로 쓰거나 설치가 확인된 것**만 보여줍니다.

| 도구 | 현재 상태 | 용도 |
|---|---|---|
| GitHub | 사용 중 | 저장소, 문서, 커밋, PR, Actions |
| Remote Desktop Commander | 사용 중 | 실제 PC 파일·명령·빌드·실행·기기 검증 |

| Supabase | 청약 프로젝트용 | DB/인증/프로젝트 연결 |

## Jev 핵심 사용법

TypeSafe에서 API 키를 발급해 Windows의 `JEV_API_KEY`에 넣고 새 터미널에서 `jev-codex`를 실행합니다. 이후 평소처럼 작업을 입력하면 Jev가 모델 등급을 선택하고 실제 작업은 Codex가 수행합니다.

API 키 설정과 Threads 저장소의 실제 라우팅은 확인했습니다. 민감한 코드·개인정보·금융·의료 자료에는 사용하지 않습니다.

## 기본 관리 위치

새로 AI가 직접 설치하거나 만드는 도구·실험 프로젝트는 기본적으로 아래 구조를 사용합니다.

`C:\Program Files\_My\AI`

```text
Applications   프로그램
Installers     설치 원본
Scripts        설치·업데이트·복구 스크립트
Launchers      바로 실행할 진입점
Projects       새 AI 프로젝트
Workspace      임시 실험
External       기본 위치를 유지하는 외부 설치 기록
```

패키지 관리자나 공식 업데이터 때문에 기본 위치를 유지하는 편이 안전하면 억지로 옮기지 않습니다.
