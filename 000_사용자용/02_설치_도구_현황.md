## Jev 핵심 사용법

TypeSafe에서 API 키를 발급해 Windows의 `JEV_API_KEY`에 넣고 새 터미널에서 `jev-codex`를 실행합니다. 이후 평소처럼 작업을 입력하면 Jev가 모델 등급을 선택하고 실제 작업은 Codex가 수행합니다.

Jev 사용은 허용되어 있고 필요할 때 선택합니다. 실제 외부 왕복은 미검증이며 비용·한도도 별도 확인합니다. 비밀값을 작업 프롬프트에 넣지 않습니다.

## 기본 관리 위치

새로 AI가 직접 설치하거나 만드는 도구·실험 프로젝트는 기본적으로 아래 구조를 사용합니다.

`D:\A_KJ\AI`

```text
Applications   프로그램
Installers     설치 원본
Scripts        설치·업데이트·복구 스크립트
Launchers      바로 실행할 진입점
Projects       새 AI 프로젝트
Workspace      임시 실험
External       기본 위치를 유지하는 외부 설치 기록
```

패키지 관리자나 공식 업데이터 때문에 기본 위치를 유지하는 편이 안전하면 억지로 옮기지 않습니다.
