## 허브가 하는 일

- 사용자 작업 규칙 관리
- 실제 프로젝트 저장소 연결
- 설치된 도구와 후보 도구 구분
- 이전 작업과 인수인계 기록
- 프로젝트 사이에서 재사용할 경험 정리

실제 코드·버전·최신 실행 상태는 각 프로젝트 저장소가 원본입니다. 허브의 오래된 요약과 실제 저장소가 다르면 실제 저장소를 우선합니다.
