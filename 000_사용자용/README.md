## 현재 한눈에 보기

- 통합 관리 저장소: **Project Operations Hub**
- 주 프로젝트: 운동앱, 주식자동매매, 청약, 멀티의신, 주식 앱, 피규어만들기, 동물의숲, AI 콘텐츠 수익화
- 공통 도구: GitHub, Remote Desktop Commander, ChatGPT Files/Library, 로컬 n8n
- 설치 확인 도구: MoneyPrinterTurbo, n8n, HyperFrames, Aider
- 후보 도구는 `가벼움 / 보통 / 무거움 / 매우 무거움`으로 따로 표시
- AI 도구/Plugin은 `바로 사용 / 연결 필요 / AI 설치 가능 / 사용자 1회 도움 / 사용자 직접 사용`까지 따로 표시
- 소통창구는 프로젝트별 방 + 주제별 스레드 + AI별 우편함 구조

## 문서 구분

```text
000_사용자용/        ← 내가 읽는 곳
00_SYSTEM/           ← AI가 허브 구조를 이해하는 곳

02_PROJECTS/         ← 프로젝트 연결 정보

04_COMMUNICATION/    ← 실제 대화 기록
05_TEMPLATES/        ← AI용 템플릿
99_ARCHIVE/          ← 과거 기록

```

사용자는 특별히 원문을 확인하고 싶을 때만 내부 폴더를 보면 됩니다.
