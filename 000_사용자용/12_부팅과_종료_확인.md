확인일: 2026-10-06. 현재 PC의 실제 시작 항목·프로세스·오류 기록을 조사했습니다.

| 항목 | 확인한 문제 / 처리 |
|---|---|
| 주식 자동매매 시작 파일 | pythonw여도 Startup CMD 자체가 콘솔을 만들 수 있습니다. 원본을 백업하고 숨김 VBS로 교체했습니다. 실제 매매 루프·인수·현재 프로세스는 변경하지 않았습니다. |

| Chrome / ZBrush | 최근 응답 없음 기록이 있습니다. 현재 종료를 막는 프로그램이라고 확정할 근거는 없습니다. |

**원격 연결 끄기:** 앱 도구·연결의 원격 연결 끄기. 이번 로그인 동안 유지합니다. 다시 켜기를 누르거나 다음 로그인하면 복구를 재개합니다. 앱 창만 닫으면 원격 연결은 유지합니다.
