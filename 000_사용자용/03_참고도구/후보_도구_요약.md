# 지금 쓸 도구 · 필요한 것만

**2026-11-03 정리.** 예전 후보 전체를 설치하지 않습니다. 실제 버전·검사 결과는 [설치 현황](../02_프로그램/설치_도구_현황.md)을 봅니다.

| 일 | 먼저 쓸 것 |
|---|---|
| 코딩·운영 | 기존 Codex/GitHub + 관제탑/ProjectBridge + AGENTS/Engram |
| 파일·JSON | 기존 rg/fd + jq |
| Python·PowerShell 검사 | uv + Ruff / PSScriptAnalyzer |
| 비밀값 검사 | Gitleaks CLI, 결과 redact |
| 문서·웹 조사 | 현재 문서/웹 도구. 부족하면 MarkItDown 선택 검토 |
| 앱 의미 기반 보조 | agent-desktop 수동 CLI; help 검사 ≠ 화면 검증 |

n8n은 반복 흐름, Playwright는 웹 테스트, 언어별 검사기는 해당 파일에만 씁니다. Apify/Firecrawl/Context7은 계정·한도·작업 비용 확인 후에만 연결합니다. browser-use/Stagehand는 기본 브라우저로 안 되는 일이 생기면 하나만 비교합니다. 음성/영상/Blender/금융 조사는 해당 프로젝트에서만 검토합니다.

중복 기억 서버·Agent 관제·대형 harness·모델/서버는 **현재 추천에서 뺐습니다**. 과거 조사는 참고만 남겼으며 설치 대기열이 아닙니다. Bytebot는 공식 보관 저장소로 신규 도입 제외. OpenMausBot는 중복 구성/별도 cloud 비용 가능성으로 보류합니다.

ComfyUI는 요청대로 목록에서 제거했습니다. **PC의 기존 앱·모델·작업 자료는 삭제하지 않습니다.** 추가 결제·유료 API·새 구독·autostart 없이 진행하며 로그인/UAC/CAPTCHA는 사용자 대기로 남깁니다.
