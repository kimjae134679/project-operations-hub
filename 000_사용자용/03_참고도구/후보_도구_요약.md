## 설치 부담 표기

- ⚪ 설치 불필요 — 문서·목록·참고자료
- 🟢 가벼움 — 단일 CLI/패키지/작은 도구
- 🟡 보통 — Python/Node 환경, 로컬 서버, 브라우저 런타임 등
- 🟠 무거움 — Docker 여러 개, 큰 모델, DB, 수 GB 이상 가능
- 🔴 매우 무거움 — GPU/CUDA, 대형 모델, 높은 RAM·디스크, 여러 서비스가 겹침

## 먼저 볼 가치가 큰 후보

| 도구 | 부담 | 어디에 쓸 후보인지 |
|---|---|---|
| Ruff | 🟢 | Python lint+format. `uvx`로 영구 설치 없이도 실행 가능 |
| ty (Astral) | 🟢 | Python 정적 타입 검사. `uvx ty check`로 영구 설치 없이 시험 가능; 초기에는 기존 mypy/Pyright의 보조 검사기로 비교 권장 |
| ShellCheck | 🟢 | Bash/sh 정적 분석. shell script·Git Bash·WSL·CI 스크립트 오류를 실행 전에 검사; BAT/PowerShell 전용 도구는 아님 |
| shfmt | 🟢 | Bash/sh 계열 포맷터. `shfmt -d`로 먼저 차이만 확인하고 필요할 때 `-w`; ShellCheck와 역할 분리 |
| PSScriptAnalyzer | 🟢 | PowerShell `.ps1/.psm1/.psd1` 정적 분석. Windows 빌드·설치·원격 스크립트 검증용; `-Fix`보다 검사→diff→재검사 우선 |
| actionlint | 🟢 | GitHub Actions workflow 문법·expression·정합성 검사 |
| zizmor | 🟢 | GitHub Actions 보안 정적 분석. template injection·과도한 permissions·credential/pinning 등 보안 패턴 검사; `actionlint`와 보완 관계 |
| lychee | 🟢 | Markdown/HTML/문서의 깨진 링크 검사. 외부 사이트 403/429·bot 차단은 실제 broken link와 구분하고, ignore 남발 금지 |
| typos (`crate-ci/typos`) | 🟢 | 코드·README·설정의 흔한 영문 오타 검사. 자동 수정 전 diff 확인 |
| dprint | 🟢 | 여러 언어 formatter를 `dprint fmt` 하나로 묶는 통합 포맷 계층. Wasm plugin은 sandbox, process plugin은 별도 신뢰 검토 필요 |
| pre-commit | 🟢 | Ruff·Gitleaks·typos 같은 검사를 Git commit 전에 한 흐름으로 묶는 무료 오픈소스 hook 관리자. 외부 hook은 실행 전 출처/rev 검토 |
| reviewdog | 🟢 | 여러 lint/보안 검사 결과를 변경된 diff 중심으로 모아 로컬 또는 GitHub PR/Checks에 전달. 로컬은 AI 단독 가능, PR 게시 권한은 1회 준비가 필요할 수 있음 |
| OSV-Scanner | 🟢 | Google OSV 기반 dependency/lockfile 취약점 검사. 단순 의존성 검사는 Trivy보다 좁고 가볍게 시작 가능; 자동 `fix`보다 scan-only 우선 |
| Trivy | 🟡 | dependency/container/IaC 취약점·secret·license·SBOM 통합 검사. 공급망 이력 때문에 버전/provenance 확인과 GitHub Action full SHA pinning을 전제로 선택 적용 |
| mise | 🟢~🟡 | Node/Python/Go 등 여러 개발도구 버전·환경변수·반복 task를 `mise.toml`로 재현. 단순 프로젝트에 억지 도입하지 않고 다중 런타임/환경 재현 문제가 있을 때 검토 |
| Vercel Skills | 🟢 | Codex/Claude/Cursor 등의 스킬 검색·설치·업데이트 |
| OpenViking | 🟡 | 프로젝트 기억·지식·스킬을 구조화해서 관리 |

## 특히 무거운 것은 따로 취급

### 🔴 ComfyUI
앱 자체보다 체크포인트·LoRA·VAE·영상 모델·PyTorch/CUDA 때문에 실제 용량과 GPU 부담이 크게 늘어납니다. 가볍게 시험할 후보와 같은 취급을 하지 않습니다.

### 🔴 vLLM
개인용 간단 챗보다는 고성능 추론 서버 성격입니다. 모델·VRAM·CUDA/커널 호환성이 핵심 부담입니다.

### 🔴 RAGFlow
직접 운영 시 CPU/RAM/디스크와 Docker 계층이 필요한 별도 플랫폼으로 취급합니다.

### 🔴 대형 DeepSeek 계열 로컬 모델
`DeepSeek` 하나가 단일 프로그램이 아니므로 실제 모델과 양자화 방식이 정해진 뒤 별도로 판단합니다.
