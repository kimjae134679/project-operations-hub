## Codex에서 바로 부를 것

새 Skill 12개(Replica 11개 + Windows 1개)는 Codex `skills/list(forceReload)`에서 enabled, 파서 오류0으로 확인했습니다. 새 턴/세션 갱신 후 다음처럼 지정합니다.

- `$replica-recon` — 허용된 공개 자료/자기 계정의 앱 화면·흐름 정리.
- `$replica-design`, `$replica-diff`, `$replica-test` — 디자인 토큰/차이/검사 요구에 맞춰 선택.
- `$agent-desktop-windows` — 기존 Windows CLI의 사용법·제약 확인. **이름을 부르는 것만으로 화면 조회/제어 권한이 생기지 않습니다.**

설치는 기존 Skill·AGENTS·hook을 덮지 않았습니다. 실제 결제/환불·배포를 자동 수행하라는 기본 지침과 보안 우회 조언은 제거/제한했습니다. 외부 게시·계정·실결제·실제 화면 작업은 해당 요청의 별도 허가가 필요합니다.

## Apify: 지금 연결된 것은 공식 문서 전용

Codex MCP 이름은 **`apify-docs`**, 도구는 `search-apify-docs`와 `fetch-apify-docs` 두 개입니다. 새 턴/세션 갱신 뒤 “Apify 공식 문서에서 Actor 실행 방식을 찾아줘”처럼 요청할 수 있습니다. 기존 MCP 11개와 동등한 구성을 보존하고 이 항목만 추가했으며 private 백업은 공개 저장소에 넣지 않았습니다.

실제 stdio 초기화·도구 목록과 `https://docs.apify.com/actors/running`의 **6,456자 조회**를 확인했습니다. 토큰을 비우고 별도 빈 HOME을 사용하며 telemetry/Sentry는 껐습니다. 웹 전체 수집/Actor 실행/데이터셋 사용은 하지 않았습니다.

로컬 수동 입구는 `D:/A_KJ/AI/Tools/apify-mcp-server/0.20.0/Start-ApifyMcp.cmd`입니다. 기본 Docs 모드는 MCP 클라이언트용 stdio라 일반 창에 채팅 UI가 생기지 않습니다. `-Mode Discovery`는 세션의 `APIFY_TOKEN`이 없으면 exit3으로 명확히 멈춥니다. 별도 token/계정 연결과 비용 확인 없이 Actor를 실행하지 않습니다. 무료 runtime ≠ 무료 무제한 스크래핑.
