`D:/A_KJ/AI/Launchers/개발도구_콘솔.cmd`를 원할 때 실행하면 **그 콘솔에서만** 새 도구 경로/모듈을 불러옵니다. 새 상시 실행·로그인 시작은 없습니다. 기본 작업 폴더는 별도로 만든 clean 허브 `D:/A_KJ/AI/Projects/project-operations-hub-current`입니다. main·clean 상태와 GitHub origin을 확인했고, 기본 PowerShell 정책으로 콘솔 환경을 로드해 이 경로 선택과 새 검사 도구 해석을 확인했습니다. 기존 dirty 저장소는 그대로 보존했습니다. 폴더 미존재 시만 이번 Codex 작업 폴더로 대체합니다. 최종 원격 main 동기화는 별도 확인합니다.

콘솔 환경 검사 3/3, 기본 PowerShell 정책 로드 exit0입니다. **실제 콘솔 창·앱 조작은 실행하지 않았습니다.** 도구 경로는 전역 PATH에 넣지 않았습니다. 콘솔 안에서 예를 들어 `jq --version`, `ruff --version`, `Get-Module -ListAvailable PSScriptAnalyzer`, `agent-desktop version`으로 설치를 확인할 수 있습니다.

콘솔에서 파일을 명시해 `ruff check 경로/파일.py`, `Invoke-ScriptAnalyzer -Path 경로/파일.ps1`로 읽기 전용 검사를 시작합니다. 자동 수정 옵션은 넣지 않습니다. 검사 경고와 실제 오류를 구분해 필요한 것만 고칩니다.

실무는 `기존 자료 확인 → 최소 수정 → Ruff/PSScriptAnalyzer 등 해당 검사 → diff → 필요한 test/build` 순서입니다. Gitleaks는 결과 redact, 자동 fix·전체 포맷·화면 조작·추가 API 호출은 별도입니다.
