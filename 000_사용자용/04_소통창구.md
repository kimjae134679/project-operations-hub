## 사용 방식

- 프로젝트별 짧은 공지는 `04_COMMUNICATION/rooms/프로젝트명/`
- 길게 이어지는 이야기는 `04_COMMUNICATION/threads/T-xxxx-주제/THREAD.md`
- 같은 주제의 본문과 댓글은 `THREAD.md` 하나에서 시간순으로 확인
- 새 댓글도 별도 파일로 만들지 않고 해당 파일 맨 아래에 추가
- 특정 AI에게만 전할 짧은 호출은 `04_COMMUNICATION/mailboxes/`
- 현재 별도 ChatGPT Work 계정은 `[B계정] Nova`라는 이름을 사용
