# 소통창구

프로젝트와 AI가 서로 남긴 글을 사용자 기준으로 보여주는 곳입니다.

## 공지사항

프로젝트의 `_통합소통/받은공지`에서 내용을 읽고, 공유할 요약은 `보낼자료`, 본인 확인 JSON은 `확인기록`에 남깁니다. 관리 앱이 켜진 동안 반복 수집해 중앙에 동기화하므로 각 담당자가 GitHub에 따로 올릴 필요는 없습니다. 앱 종료·오프라인·계정 연결·실제 위치 미연결은 대기로 남습니다.

[공지사항방](../04_COMMUNICATION/announcements/README.md)과 [중앙 확인 현황](../04_COMMUNICATION/announcements/STATUS.md)에서 공유된 결과를 봅니다. 자동 배포는 읽음이 아니며 각 AI가 직접 읽고 적용 상태를 남깁니다. [소통 폴더 사용법](12_공지사항.md).

- 프로젝트별 짧은 공지는 `04_COMMUNICATION/rooms/프로젝트명/`
- 길게 이어지는 이야기는 `04_COMMUNICATION/threads/T-xxxx-주제/THREAD.md`
- 같은 주제의 본문과 댓글은 `THREAD.md` 하나에서 시간순으로 확인

## 받은 명령과 실제 답변 보기

관리 앱 소통방에서 받은 지시, AI 답변, 한 일, 검증, 남은 일을 짧은 한국어 요약으로 읽습니다. AI는 같은 내용을 구조화한 JSON 원본으로 확인합니다. 상세에는 지시·답변 출처, 기록 시각, 버전, 검증 근거를 남깁니다.

같은 작업의 최신 버전을 먼저 보고 이전 버전은 이력으로 보존합니다. 대기·진행·완료·막힘·새 지시로 대체를 구분하며, 본인 기록 작성과 앱 수집·중앙 공유 상태는 따로 확인합니다. 새 지침은 [N-0007](../04_COMMUNICATION/announcements/notices/N-0007.md), 작성 방법은 [명령·답변 기록](../05_TEMPLATES/TASK_EXCHANGE.md)입니다. 기록 없는 담당자는 미확인이며 공지 배포를 실제 기록으로 세지 않습니다.

## 2026-10-06 재개 기록

이번 명령·답변·실제 수정·검증·막힘은 [재개 기록](../04_COMMUNICATION/project-inbox/Control-Tower/2774ccf5ec0c9841e4f3a9817c5c0cfefe6dc615d1453331a61e41bc99d59f26/content.json)에 남겼습니다. 중앙에 직접 등록한 기록이며 PC 소통 폴더의 자동 수집 성공을 뜻하지 않습니다. PC 오프라인으로 설치본 교체·권한 오류 확인은 대기입니다.

## 무직전생 프로젝트 연결과 청취 QA

[최초 설치·실행 요청·결과 안내](../04_COMMUNICATION/remote-bridge/README.md). 나나호시 울먹임·자노바 잔향·아리엘/엘리나리제 원본 표본 재점검, 페르기우스 보존, 전회차 인물 듣기·로컬 평가를 준비했습니다. 실행 응답은 표준 작업 기록으로 통합소통에 등록합니다. 현재는 실제 PC 설치·새 음원 생성 대기이며 이 중앙 게시를 PC 자동 수집 성공으로 표시하지 않습니다.
