# 후보 도구 요약

인터넷/GitHub에서 찾은 도구 중 실제 검토 가치가 있는 것만 사용자 기준으로 압축합니다.

## 설치 부담 표기

- ⚪ 설치 불필요 — 문서·목록·참고자료
- 🟢 가벼움 — 단일 CLI/패키지/작은 도구
- 🟡 보통 — Python/Node 환경, 로컬 서버, 브라우저 런타임 등
- 🟠 무거움 — Docker 여러 개, 큰 모델, DB, 수 GB 이상 가능
- 🔴 매우 무거움 — GPU/CUDA, 대형 모델, 높은 RAM·디스크, 여러 서비스가 겹침

## 먼저 볼 가치가 큰 후보

| 도구 | 부담 | 어디에 쓸 후보인지 |

## 특히 무거운 것은 따로 취급

### 🔴 ComfyUI
앱 자체보다 체크포인트·LoRA·VAE·영상 모델·PyTorch/CUDA 때문에 실제 용량과 GPU 부담이 크게 늘어납니다. 가볍게 시험할 후보와 같은 취급을 하지 않습니다.

### 🔴 vLLM
개인용 간단 챗보다는 고성능 추론 서버 성격입니다. 모델·VRAM·CUDA/커널 호환성이 핵심 부담입니다.

### 🔴 RAGFlow
직접 운영 시 CPU 4코어+, RAM 16GB+, 디스크 50GB+와 Docker 계층이 필요합니다.

### 🔴 대형 DeepSeek 계열 로컬 모델
`DeepSeek` 하나가 단일 프로그램이 아니므로 실제 모델과 양자화 방식이 정해진 뒤 별도로 판단합니다.

## 아직 확인이 덜 된 것 / 문제 있는 원문

현재까지 보낸 자료 중 완전히 해결되지 않은 것은 아래입니다.

| 항목 | 현재 상태 | 문제 |
|---|---|---|
| `iFixAi` | 확인 보류 | 게시물의 `ifixai-ai/iFix` 경로가 현재 404라 정확한 원본을 특정하지 못함 |
| `agent-skills`라는 일반명 | 확인 보류 | 동명/유사 저장소가 많아 사용자가 본 정확한 저장소를 특정하지 못함. 현재는 `anthropics/skills`와 Agent Skills 규격을 대표 참고로 연결 |
| `Aura_lixx` X 게시물 | 원문 미확인 | X status 본문을 직접 불러오지 못함. 사용자가 준 링크/스크린샷 내용만 보존 |
| `shanyanggm` X 게시물 | 원문 미확인 | X status 본문을 직접 불러오지 못함. 사용자가 준 링크/스크린샷 내용만 보존 |
| 최근 3개 X 목록 (`ayush26291`, `DivyanshT91162`, `AISimplifyX`) | 내용 처리 완료 / X 원문 자체는 별도 보장 안 함 | 사용자가 채팅에 붙여준 목록은 전부 읽고 정리했고, 실제 판단은 공식 GitHub/README 기준으로 다시 검증함 |

즉 **내용 자체를 놓친 큰 묶음은 현재 확인되지 않았고**, 위 항목들만 원문 특정/직접 조회가 덜 된 상태입니다.

50개 목록에서는 `#48~50`이 앞 항목과 중복이었고, MetaGPT·Firecrawl·ComfyUI·LobeHub는 저장소 이동/이름 변경이 있어 현재 위치로 보정했습니다. `DeepSeek`은 단일 프로그램이 아니라 여러 모델 저장소를 가진 조직이라 모델별로 다시 판단해야 합니다.

## 설치하지 않고 참고만 하는 자료

`public-apis`, `build-your-own-x`, `developer-roadmap`, `free-programming-books`, `system-design-primer`, `the-art-of-command-line`, `freeCodeCamp`, `awesome-selfhosted`, `prompts.chat`, 각종 awesome skills 목록 등은 기본적으로 설치 대상이 아니라 필요할 때 찾는 자료입니다.

## 중요한 구분

`GitHub에서 좋아 보임` ≠ `설치됨` ≠ `실제로 채택해서 쓰는 중`

후보는 검토 후에도 후보로 남고, 실제 설치·테스트가 확인되어야 사용 중 상태로 올립니다.
