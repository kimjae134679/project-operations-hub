# 후보 도구 요약

인터넷/GitHub에서 찾은 도구 중 실제 검토 가치가 있는 것만 사용자 기준으로 압축합니다.

## 설치 부담 표기

- ⚪ 설치 불필요 — 문서·목록·참고자료
- 🟢 가벼움 — 단일 CLI/패키지/작은 도구
- 🟡 보통 — Python/Node 환경, 로컬 서버, 브라우저 런타임 등
- 🟠 무거움 — Docker 여러 개, 큰 모델, DB, 수 GB 이상 가능
- 🔴 매우 무거움 — GPU/CUDA, 대형 모델, 높은 RAM·디스크, 여러 서비스가 겹침

## 특히 무거운 것은 따로 취급

### 🔴 ComfyUI
앱 자체보다 체크포인트·LoRA·VAE·영상 모델·PyTorch/CUDA 때문에 실제 용량과 GPU 부담이 크게 늘어납니다. 가볍게 시험할 후보와 같은 취급을 하지 않습니다.

### 🔴 vLLM
개인용 간단 챗보다는 고성능 추론 서버 성격입니다. 모델·VRAM·CUDA/커널 호환성이 핵심 부담입니다.

### 🔴 RAGFlow
직접 운영 시 CPU 4코어+, RAM 16GB+, 디스크 50GB+와 Docker 계층이 필요합니다.

### 🔴 대형 DeepSeek 계열 로컬 모델
`DeepSeek` 하나가 단일 프로그램이 아니므로 실제 모델과 양자화 방식이 정해진 뒤 별도로 판단합니다.

## 설치하지 않고 참고만 하는 자료
