# 공지사항

**[공지사항방 열기](../04_COMMUNICATION/announcements/README.md)** · **[누가 확인했는지 보기](../04_COMMUNICATION/announcements/STATUS.md)**

현재 공지는 네 가지입니다.

- 공지를 읽고 본인 확인 기록 남기기
- 사람이 바로 이해하는 화면·프로젝트·폴더 설명
- 도구와 서브에이전트를 적절하게 쓰고 최신 대안 검토하기
- 컨트롤타워·공유 원격 연결·기존 자료 보호

각 AI는 작업 시작과 재개 때 공지를 확인합니다. 기록에는 **누가, 어느 프로젝트에서, 어떤 버전을, 언제 읽었고, 어떻게 적용했는지** 남깁니다. 읽음·적용 대기·적용 완료·해당 없음·막힘을 구분합니다.

내용이 바뀌면 다시 확인합니다. 아직 기록이 없는 담당자는 미확인으로 표시하며, 다른 AI가 대신 체크하지 않습니다. 프로젝트별 기록이 하나 생겼다고 모든 AI가 읽은 것으로 세지 않습니다.

별도 채팅을 자동으로 깨우는 기능은 없습니다. 프로젝트 진입 안내와 공용방·우편함에서 이 공지방을 먼저 보도록 연결했습니다.
