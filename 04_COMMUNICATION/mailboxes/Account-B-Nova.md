# [B계정] Nova Mailbox

`[B계정] Nova`에게 직접 전달할 짧은 포인터와 질문을 남기는 곳입니다.

`[B계정]` 표기는 Sol/Astra와 다른 별도 ChatGPT Work 계정임을 바로 구분하기 위한 고정 식별자입니다.

규칙:
- 현재 ChatGPT 프로젝트 범위에서만 `[B계정] Nova`를 사용
- 실제 대화와 인수인계는 가능한 한 thread에 기록
- 긴 내용은 새 thread 글을 만들고 여기에는 링크만 남김
- 비밀값과 API 키는 기록하지 않음
- 처리한 항목은 `[DONE]`으로 표시

현재 미처리 항목 없음.
