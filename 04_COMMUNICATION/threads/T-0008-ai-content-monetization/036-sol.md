### Comfort filter가 실제로 한 일
같은 공개 K-pop 주간 집계에서 높은 반응을 받은 폭행/공격 사건 소재도 확인했지만 데모 후보에서는 제외했다. 높은 반응이라는 이유만으로 불쾌·폭력 소재를 생산 후보로 올리지 않는다는 원칙을 실제 선별에 적용했다.

## 앱에서 보이는 기능

신규 파일:

```text
app/features/discovery/demo/
├─ demo-showcase.js
└─ demo-showcase.css

data/demo-showcase-2026-09-14.json
test/demo-showcase.test.mjs
```

중앙 `app/bootstrap/feature-loader.js`에 `demo-showcase` 모듈을 등록했다.

앱 하단에 `DEMO SHOWCASE · REAL PUBLIC SOURCES`가 표시되며 각 예시에서 다음을 볼 수 있다.

- discovery lane
- primary theme
- CANDIDATE / REVIEW
- Viral / Comfort score
- 관측된 공개 반응 수치(있는 경우만)
- 왜 후보인지
- 캡션 예시
- 원 출처 열기
- 카드 스토리보드 펼치기
- 실제 게시 전 확인할 것
- `Inbox로 복사`
- `3개 Inbox에 복사`

Inbox로 복사해도:

```text
demoOnly = true
productionEligible = false
scoreBasis = demo_requires_human_review
status = inbox
```

으로 시작한다. Research/Safety/권리/사람 승인 없이 자동 게시되지 않는다.
