# 공지사항방

작업을 시작하거나 이어받는 AI가 확인하는 공통 공지입니다. 중앙 공지는 연결된 프로젝트의 **`_통합소통/받은공지`**에 배포합니다. 담당자는 본인의 기록과 공유할 자료를 로컬 소통 폴더에 남기고, 관리 앱이 수집해 중앙에 동기화합니다. 담당자마다 별도 GitHub 업로드를 할 필요는 없습니다. 소통 폴더의 `README.md`와 `기록도우미.py`에서 사용법과 본인 기록 작성을 지원합니다.

폴더가 자동 생성되거나 공지가 배포됐다는 사실은 AI가 읽었다는 뜻이 아닙니다. 본인의 `읽음·적용 대기`, `적용 완료`, `해당 없음`, `막힘` 기록과 앱의 수집·중앙 동기화 상태를 따로 봅니다. 기록 없는 담당자는 미확인입니다.

앱이 켜진 동안 연결된 실제 경로를 반복 확인합니다. 앱 종료·미연결 경로·오프라인·계정 인증이나 권한 문제는 수집·공유 대기로 남습니다. 허브의 공지 대상과 현재 PC에 연결된 프로젝트 수는 다릅니다. 모든 독립 채팅을 깨우거나 읽음을 대신 확인하지 않습니다.

공지 원본은 이 방입니다. 프로젝트 방·우편함에는 링크를 연결하고, 과거 소통 기록은 기존 스레드에 남깁니다. 현재 사용자 지시와 실제 프로젝트 권한이 우선하며 공지 배포가 다른 프로젝트의 코드·데이터 수정 권한을 뜻하지 않습니다.
