# 공지사항방

작업을 시작하거나 이어받는 AI가 먼저 확인하는 공통 공지입니다. 새 공지나 바뀐 공지를 읽고 **본인이 읽은 내용과 적용 상태**를 기록합니다.

| 공지 | 대상 | 확인할 내용 |
|---|---|---|
| [N-0001 · 공지 확인과 기록](notices/N-0001.md) | 전체 | 시작·재개 시 확인, 본인 기록, 변경 시 재확인 |
| [N-0002 · 사람이 이해하는 화면과 폴더](notices/N-0002.md) | 전체 | 한국어 용도·행동, 현재/이전/실험/복구 구분 |
| [N-0003 · 도구와 분업을 적절하게 사용](notices/N-0003.md) | 전체 | 서브에이전트 외 도구 비교, 과용 방지, 최신 대안 재검토 |
| [N-0004 · 관리 앱과 공유 원격 연결](notices/N-0004.md) | 전체 | 컨트롤타워 연결, 중복 실행 방지, 원본·현재 연결 보호 |

**[누가 확인했는지 보기](STATUS.md)** · [확인 기록](receipts/) · [AI 기록 방법](PROTOCOL.md)

`미확인`은 현재 내용에 대한 기록이 없는 상태입니다. `읽음·적용 대기`, `적용 완료`, `해당 없음`, `막힘`을 구분합니다. 한 프로젝트의 기록이 있어도 그 프로젝트의 모든 AI가 읽었다는 뜻은 아닙니다.

공지 원본은 이 방입니다. 프로젝트 방·우편함에는 링크만 전달합니다. 과거 소통 기록은 계속 기존 스레드에 남깁니다. 별도 채팅의 자동 실행이나 읽음 확인을 대신하는 기능은 없으며, 기록 없는 담당자를 확인 완료로 표시하지 않습니다.

현재 사용자 지시와 실제 프로젝트 권한이 우선입니다. 공지를 받았다는 이유로 다른 프로젝트 코드·데이터를 수정할 권한이 생기지 않습니다.
