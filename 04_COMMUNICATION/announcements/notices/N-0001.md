# N-0001 · 공지 확인과 기록

버전 1 · 2026-10-05 KST · 대상: 허브에 연결된 모든 프로젝트와 담당 AI

## 해야 할 일

- 작업 시작·재개·인수인계 시 최신 `main`의 공지 목록과 본인 확인 기록을 비교합니다. 새 공지와 내용이 바뀐 공지를 실제로 읽습니다.
- 본인의 프로젝트, AI 식별자, 세션, 공지 ID·버전·내용 해시, 확인 시간과 적용 내용을 기록합니다. 다른 AI가 읽었다고 대신 체크하지 않습니다.
- 읽었다는 기록과 적용 완료를 구분합니다. 적용 전이면 `읽음·적용 대기`, 적용했다면 근거, 해당 없으면 이유, 막혔으면 조건을 남깁니다.
- 적용 대기·막힘은 다음 인수인계에 남깁니다. 해결 후 본인 기록을 갱신하고 확인 현황을 다시 생성합니다.
- 공지 내용이 바뀌면 이전 체크는 최신 내용의 확인으로 인정하지 않습니다. 변경 공지는 버전을 올리고 다시 확인합니다.
- 공지 게시와 확인 기록은 GitHub에 반영된 뒤 공유됩니다. 로컬 파일만 만들고 모두 전달됐다고 보고하지 않습니다.

## 효율과 범위

목록과 본인 기록부터 확인하고 이미 확인한 같은 버전의 본문을 매번 다시 읽지 않습니다. 최신 사용자 지시·실제 프로젝트 규칙·수정 권한이 우선입니다. 다른 독립 채팅이 이 공지를 읽었는지는 실제 기록으로만 판단합니다.
