# N-0008 · 프로젝트 사용 안내를 먼저 읽고 함께 관리하기

- 버전: 1
- 대상: 허브에 연결된 모든 담당 AI
- 시행 근거: 2026-10-06 사용자 최신 지시

각 담당자는 자기 프로젝트 실제 작업 폴더에 사용 안내를 작성·갱신합니다. `00_사용안내.md` 또는 `00_사용안내.txt`를 권장하며 이미 쓰는 안내는 유지할 수 있습니다. 표준과 앱에서 읽는 파일명은 허브 `05_TEMPLATES/PROJECT_USER_GUIDE.md`를 따릅니다.

사용자가 어느 파일을 열면 무엇을 듣거나 볼 수 있는지, 다른 자료와 입력·결과·보관 폴더가 어디에 있는지, 실행 방법과 현재 상태를 쉽게 설명합니다. 무직전생에서는 최신 음원·비교 음성·캐릭터 표본·원본 영상·텍스트·과거 결과를 각각 실제 위치와 함께 설명합니다. 필요한 화면 이미지는 로컬 Markdown 이미지로 연결합니다.

위치와 용도는 실제 프로젝트에서 확인합니다. 미확인 경로를 추측하거나 준비 완료를 음원 생성·실사용 완료로 표시하지 않습니다. 원본·모델·실행기·음원을 정리를 이유로 임의 이동하지 않습니다. 여러 안내 복제본을 동시에 원본으로 유지하지 않습니다.

다음 작업·재개·인수인계 때 해당 안내를 먼저 읽고 현재 README/AGENTS, 최신 task_exchange와 실제 파일 상태를 함께 확인합니다. 변경한 안내는 프로젝트 저장소에 보존하고 소통 기록에 경로·변경 요약·검증·미확인 사항을 남깁니다. 받은 명령과 실제 답변 기록은 N-0007을 계속 따릅니다.

이 공지의 중앙 작성과 각 PC의 전달·실제 읽음·안내 작성은 별개입니다. 다른 AI의 읽음·작성 완료를 대신 표시하지 않습니다. 사용자 최신 지시와 실제 수정 권한이 우선입니다.
