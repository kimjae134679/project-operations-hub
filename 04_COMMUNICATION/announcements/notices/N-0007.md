# N-0007 · 받은 명령과 AI 답변을 이어 기록하기

- 버전: 1
- 대상: 허브에 연결된 모든 담당 AI
- 시행 근거: 2026-10-06 KST 사용자 최신 지시

## 해야 할 일

작업 시작에 실제 받은 명령의 주요 요구·제약·출처·시각을 기록합니다. 진행·완료·중단 때 **실제로 전달한 답변 요약, 한 일, 검증 근거, 남은 일, 막힘**을 갱신합니다. 새 지시가 이전 지시를 대체하면 관계를 남깁니다. 이전 작업을 이어받을 때는 최신 기록과 실제 저장소를 함께 확인합니다.

공식 원본은 task_exchange JSON입니다. 허브 `05_TEMPLATES/TASK_EXCHANGE.md`, `TASK_EXCHANGE.schema.json`, `TASK_EXCHANGE.template.json`과 소통 도우미의 record/validate/render를 사용합니다. 기존 check/ack는 공지 확인용이며 작업 명령·답변 기록과 구분합니다.

```text
py -3.11 기록도우미.py validate --input 작업기록.json
py -3.11 기록도우미.py record --input 작업기록.json
py -3.11 기록도우미.py render --input 작업기록.json
```

도우미가 아직 갱신되지 않았으면 형식에 맞춘 JSON을 본인 `_통합소통/보낼자료`에 직접 작성하고 도우미 갱신 대기를 남깁니다. 실제 프로젝트 ID는 받은공지/manifest.json에서 확인합니다. 받은 명령과 수신 시각은 같은 recordId 이력에서 유지하고 revision을 올립니다. 새 지시는 새 ID를 사용하며 다른 AI를 대신 기록하지 않습니다.

## 사람이 읽는 요약과 AI 원본

사용자에게는 “받은 지시 → AI 답변 → 한 일 → 검증 → 남은 일” 순서로 쉬운 한국어를 보여줍니다. AI는 같은 JSON의 상세·출처·시간·버전·검증을 읽습니다. 사람이 읽는 별도 Markdown을 복제 원본으로 관리하지 않습니다. 상태는 대기·진행 중·완료·막힘·새 지시로 대체를 구분합니다.

최종 답변 전에는 실제 진행 답변 또는 “최종 답변 대기”로 적고 최종 전달 후 실제 내용에 맞춰 갱신합니다. 예정 답변을 실제 답변으로 만들거나 일부 구현을 완료라고 적지 않습니다. 검증하지 않은 것은 미실행으로 남깁니다. 비밀값과 개인 대화 원문 전체는 기록하지 않습니다.

## 성공을 섞지 않기

규칙 발표·도우미 배포, 본인 JSON 작성, 앱 수집, 중앙 공유, 실제 공지 읽음·적용은 각각 다른 상태입니다. 앱이 종료됐거나 경로·인증·네트워크 문제가 있으면 공유 대기를 남깁니다. 이 공지를 배포했다고 다른 AI가 읽었거나 독립 채팅 전체가 상시 자동 기록된다고 주장하지 않습니다. 본인 공지 확인 기록만 남깁니다. 현재 사용자 지시와 실제 프로젝트 권한이 우선입니다.
