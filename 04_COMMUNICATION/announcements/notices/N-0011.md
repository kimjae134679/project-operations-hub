# N-0011 · 승인된 연속 작업과 보존·권한 경계

- 버전: 1
- 대상: 통합소통에 연결된 모든 프로젝트 담당 AI
- 근거: 2026-10-07 현재 사용자 지시와 설계 승인

## 승인한 범위

과거 Jev 로컬 사용 금지는 폐기됐습니다. Jev는 선택 경로이며 설치·키 존재와 실제 모델 지원·인증·비용·업무 성공을 구분합니다. 사용자는 기존 사용량 범위에서 프로젝트·요청자별 큐, 후속 단계, 체크포인트, 실제 기록과 소유 작업 중지를 승인했습니다. 승인된 다음 단계만 진행하고, 빈 큐에서 새 일을 무한 생성하거나 다른 프로젝트 권한을 확대하지 않습니다. 대화가 끝난 뒤 실행은 실제 지원되는 로컬 실행기에 한정합니다.

반복 검사·상태 조회·기존 명령 실행은 가능하면 결정론적 코드로 처리해 불필요한 모델 호출을 줄입니다. 안정적인 작업 ID와 기존 결과를 확인하고, 실행 여부가 모호한 수정·설치는 자동 재실행하지 않습니다. 받은 명령·실제 답변·변경·검증·남은 일·소유 작업 ID·다음 구체적인 행동을 본인 task_exchange에 기록합니다. 기록·동기화 실패 때문에 작업을 재실행하지 않습니다.

## 보존과 권한 경계

바탕화면의 파일·폴더·바로가기를 생성·수정·이동·삭제하지 않고, 기존 창을 이동·재배치하거나 포커스를 빼앗지 않습니다. 기존 바탕화면 입력 자료는 읽기만 허용합니다. 새 작업·검사·로그는 확인된 관리 작업 폴더에 둡니다. 기존 원격 연결, 다른 프로젝트의 수정·미저장 자료·원본·Known-Good와 생성 중인 VoiceAudiobook 작업을 보존합니다. 중지는 실행기가 소유한 작업만 대상으로 합니다.

추가 결제·무료체험 전환, Astra 모델, 계정·플랫폼 권한 변경, 원본 대량 삭제와 외부 게시·게시 예약 활성화는 이번 승인 범위에서 제외합니다. 일반적인 승인 질문을 줄이려는 요청은 UAC·잠금 화면·인증·서비스의 안전 제한을 우회하거나 전역 권한을 바꾸라는 뜻이 아닙니다. 실제 권한 부족·비용·모델 지원 문제가 있으면 막힘과 다음 행동을 기록합니다.

새 모델 호출은 실제 실행 지원이 확인된 이름을 명시합니다. N-0010의 6.1 우선·Astra 제외 기준을 유지하되 목록 표시만으로 계정의 실행 성공을 단정하지 않습니다. 지원 거부는 반복 호출하지 않고 현재 실행기·계정 지원을 확인합니다. 검증된 비Astra 대체 모델을 사용하면 요청 모델·실제 모델·이유·실행 결과를 해당 task_exchange에 남깁니다. 특정 과거 실패나 대체 모델을 전역 정책의 고정 모델로 만들지 않습니다. Astra 제외나 추가 과금 방지를 보장할 수 없는 자동 라우팅은 쓰지 않습니다.

## 진행 순서와 실제 확인

먼저 통합 프로그램·작업용 원격과 복구 기반을 실제 결과로 검증합니다. 그다음 각 프로젝트 담당 AI에게 최신 공지를 실제 읽고 본인 프로젝트·작성자·세션·버전·해시로 확인 기록을 남기도록 요청합니다. 배포·앱 수집·중앙 동기화·읽음·적용은 각각 별개이며 다른 AI의 확인을 대신 작성하지 않습니다. 연락할 수 없는 담당자는 미확인 또는 막힘으로 남깁니다.

기반 확인 후 Threads 수익화와 무직전생을 실제 프로젝트의 사용 안내·최신 인수인계·기존 수정·사용자 평가·현재 제작 상태에 따라 이어갑니다. 생성 중인 오디오북을 중복 시작하거나 이전 판의 일시정지를 현재 판에 적용하지 않습니다. Threads의 평가·권리 검수는 외부 게시 승인과 다릅니다. 이 공지를 작성한 것은 프로그램 완성, 모든 AI의 읽음 또는 두 프로젝트 완료를 뜻하지 않습니다.
