# N-0010 · 대화 중단 전 기록과 연속 작업·모델 선택

- 버전: 1
- 대상: 통합소통에 연결된 모든 프로젝트 담당 AI
- 근거: 2026-10-07 사용자 최신 지시

긴 채팅 하나로 중단 한계까지 작업을 끌지 않습니다. 완료 가능한 작은 단위로 진행하고, 문맥·실행 시간 한계에 가까워지기 전에 안전한 중단점에서 기록합니다. 중단 직전까지 진척시키되 기록할 여유를 남깁니다. 강제 중단 전에 받은 명령, 실제 변경·기준 커밋, 실제 답변, 완료·진행·막힘, 검증 결과, 실행 중인 소유 작업 ID, 다음에 실행할 구체적인 명령과 완료 조건을 task_exchange의 nextActions 등에 저장합니다. 로컬 보낼자료를 우선 사용하고 기존 앱이 나중에 중앙 동기화합니다.

대화가 끝나도 이미 시작된 소유 작업과 예약된 승인 작업은 실행기가 실제 지원하는 범위에서 이어갑니다. 실행기는 프로젝트·요청자별 상태와 작업 공간을 나누고 같은 원본 수정은 순서대로 처리합니다. 재개 전 기존 실행·결과·중복 ID를 확인하고 모호한 파일 변경·설치를 무조건 재실행하지 않습니다. 자동 재개가 지원되지 않으면 다음 명령과 필요한 입력·작업 위치·성공 조건·막힌 이유를 미리 기록합니다. 종료된 ChatGPT 대화를 자동으로 깨웠거나 다른 AI가 읽었다고 대신 기록하지 않습니다.

새 모델 호출·위임은 실제 사용 가능한 6.1 계열을 우선합니다. Astra 계열은 사용하지 않습니다. 모델명을 명시하고 요청·응답 모델과 지원 여부를 확인합니다. 자동 라우팅에서 Astra 제외를 보장할 수 없으면 그 경로를 쓰지 않습니다. 6.1이 거절되면 먼저 공식 최신 실행기 업데이트와 지원 목록을 확인하고 같은 실패를 반복하지 않습니다. 업데이트로 권한이 생긴다고 단정하지 않으며 다른 비Astra 모델을 쓰게 되면 모델·이유를 기록합니다. 추가 결제·무료체험 전환은 하지 않습니다.

원격 연결과 사용자 작업을 보존합니다. 업데이트는 해당 도구만 대상으로 하고 CMD·PowerShell 추가 창 없이 실행합니다. 사용자에게는 이번 진척·현재 막힘·다음 행동을 짧게 보고합니다. 공지 게시·배포·실제 읽음·작업 적용·대화 밖 지속 실행을 각각 구분합니다.
