# N-0009 · 부팅 창과 종료 방해 없는 백그라운드 실행

- 버전: 1
- 대상: 허브에 연결된 프로젝트 담당 AI
- 근거: 2026-10-06 사용자 최신 지시

자동 실행·감시·재시도·예약 작업은 사용자에게 CMD/PowerShell 창을 띄우지 않는 방식을 기본으로 합니다. Windows .NET ProcessStartInfo는 UseShellExecute=false, CreateNoWindow=true, WindowStyle=Hidden을 사용하고 Node는 확인한 실행 파일과 캐시 entry를 직접 실행합니다. Python 백그라운드는 pythonw를 사용하되 Startup CMD wrapper는 쓰지 않습니다. 작업 로그는 파일과 관리 화면에서 확인합니다.

기존 실행·자동 시작 항목을 실제 조사하고 수정 전에 백업합니다. 같은 프로젝트의 부모·자식을 중복 실행으로 단정하거나 이름만 보고 임의 종료하지 않습니다. 사용자가 실행한 편집기와 미저장 작업은 보존합니다. 전체 AutoEndTasks·전체 강제 종료로 종료 안내를 숨기지 않습니다.

원격 연결은 로그인 즉시 숨김 자동 시작하며 비정상 종료는 복구합니다. 관리 앱의 의도적 끄기는 이번 로그인 동안 자동 복구를 중단하고 다음 로그인에는 다시 켭니다. Windows 종료·로그오프를 취소하거나 종료 중 재시작하지 않습니다. 실제 프로세스/외부 Online/재부팅 검증은 구분합니다.

새 실행기·사용법·검증을 해당 프로젝트_사용안내.md와 본인 task_exchange에 반영합니다. 다른 AI의 읽음이나 적용을 대신 체크하지 않습니다.
