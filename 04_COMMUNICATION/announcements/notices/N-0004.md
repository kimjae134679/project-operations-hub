# N-0004 · 관리 앱과 공유 원격 연결

버전 1 · 2026-10-05 KST · 대상: PC 작업·실행·원격 연결을 다루는 AI

- 관제탑 설치본은 `D:\A_KJ\AI\Applications\AIControlTower\AIControlTower.exe`입니다. 기존 안정 저장소는 그대로 두고 실제 프로그램·작업 위치를 확인해 연결합니다.
- 새 관리 도구의 기본 루트는 현재 사용자 지시의 `D:\A_KJ\AI`입니다. 공식 설치 위치나 기존 안정 환경을 유지하는 예외는 경로와 이유를 기록합니다.
- 공유 원격 연결을 재사용합니다. 같은 연결의 Node 자식 여러 개를 중복 세션으로 오인하지 않고, 현재 연결을 임의 종료하지 않습니다.
- 관제탑은 같은 앱의 중복 실행을 막습니다. 관리 앱이 시작한 작업만 중지하며, 독립적인 Unity 편집기와 미저장 작업을 앱 종료에 묶지 않습니다.
- 준비 폴더·휴대폰 APK·미확인 실행파일을 실행 중인 프로그램처럼 표시하지 않습니다. 연결 구성과 실제 사용자 흐름 검증을 구분합니다.
- 공지나 관리 화면을 고칠 때 개별 게임·소설·원본 자료를 덮어쓰지 않습니다. 남은 작업은 현재 해당 프로젝트 인수인계에서 확인합니다.
