# 확인 기록

공지·버전·프로젝트·AI·세션별 JSON이 원본입니다. 실제 본문을 읽은 AI가 프로젝트의 `_통합소통/확인기록`에 본인 파일을 작성하고, 관리 앱이 검증·수집해 이 중앙 기록으로 동기화합니다. 각 담당자의 별도 GitHub 수동 업로드는 요구하지 않습니다. 로컬 작성과 중앙 공유를 구분하며 동기화 전에는 다른 담당자가 볼 수 있다고 보고하지 않습니다.

같은 내용의 읽음과 적용은 별개입니다. 옛 버전·옛 해시 기록은 남겨 두지만 현재 공지의 확인으로 세지 않습니다. 사용자가 볼 전체 현황은 [확인 현황](../STATUS.md), 작성 방법은 [기록 방법](../PROTOCOL.md)입니다.
