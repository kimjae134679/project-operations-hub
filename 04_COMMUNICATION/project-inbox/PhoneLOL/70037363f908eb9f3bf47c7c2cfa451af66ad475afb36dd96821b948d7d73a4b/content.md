# 관전 테스트 · 0.24.0

1. Unity의 **PhoneLOL → 테스트 시작 (Login)**을 열고 ▶를 누릅니다. 최초 안내를 확인하고 온라인으로 로그인합니다.
2. 휴대폰에는 **0.24.0 APK**를 설치합니다. Unity와 휴대폰에서 같은 대기방에 들어갑니다.
3. 나가기 오른쪽 **관전**을 누르면 **참가**로 바뀝니다. 다시 누르면 참가자로 돌아옵니다. 기존 챔피언 선택은 복원되고 준비는 풀립니다. 참가 자리가 꽉 차면 관전을 유지합니다.
4. 눈 아이콘 **관전 N**을 눌러 관전자 목록을 봅니다. 관전자에게 챔피언 선택·준비·전투 보상·전적은 없습니다. 관전만 있는 방은 시작하지 않습니다.
5. 참가자가 준비하면 함께 게임에 들어갑니다. 챔피언 아이콘은 위치 이동, **따라가기**는 추적, 화면 드래그/WASD는 자유 이동입니다. **+/−**, 휠 또는 두 손가락으로 확대·축소합니다. **기본 보기**는 기본 배율입니다.
6. **나가기**로 로비에 돌아옵니다. 경기 시작 후에는 관전/참가 역할을 전환하지 않습니다.

관전 기능은 같은 방의 모든 클라이언트가 build260/0.24.0 이상이어야 합니다. 혼자 플레이 메뉴는 관전 테스트용이 아닙니다.

맵을 보려면 ▶를 종료하고 **PhoneLOL → 맵 보기 → MultiGame / MtmGame**을 선택합니다. Scene에서 오브젝트를 선택하고 F를 누르면 해당 위치로 이동합니다. Inspector 수정 후 Ctrl+S로 저장합니다. 플레이 중 바꾼 씬 값은 플레이 종료 때 되돌아갑니다.

현재 프로젝트는 **D:/A_KJ/AI/PhoneLoL_02/PhoneLOL-02**입니다. 관전 UI/카메라는 Assets/Scripts/Assembly-CSharp의 PhoneLOLSpectatorLobby.cs와 PhoneLOLSpectatorCamera.cs, 역할은 PhoneLOLSpectator.cs에서 수정합니다. 서버 역할은 Automation/Server/phone_spectator.py입니다.

자동 검사와 원본 유니티 화면 검증은 통과했습니다. 새 관전 기능의 휴대폰 터치·완전한 실시간 다인 플레이는 직접 확인할 항목입니다. 기존 완료본 0.23.4는 사용자 확인 기준 정상 작동본으로 유지합니다.
