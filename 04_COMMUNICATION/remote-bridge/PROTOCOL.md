# 공용 PC 연결 규약

갱신일: 2026-11-18 KST. 현재 유지보수판은 [3.2.2](releases/20261118-v3.2.2/README.md)이다.
기본 작업 필드는 [3.0 공통 규약](releases/20261006-v3/UNIVERSAL_PROTOCOL.md)의 작업 ID·projectId·toolId·의존 관계·자원 예약 계약을 유지하며 아래 변경을 우선한다.

| 통로·상태 | 기준 |
|---|---|
| 로컬 | 인증된 127.0.0.1 API와 stdio MCP. endpoint token은 출력·공개 금지 |
| 비공개 중계 | 실제 접근 가능한 비공개 저장소·브랜치에서만 작업 요청·결과를 전달. 모든 GPT의 자동 접근 권한이 아님 |
| 현행 MCP | 엄격한 typed tools, job wait/list/log, 작업 묶음·예약·폴더 별명·페이지 검색·전송·UIA 유지 |
| 실행 결과 | acceptedResult는 최초 접수, result는 실제 상태. 장기 실행은 monitoring, 실제 종료 뒤 완료/실패 판정 |
| 충돌 | 식별자·장치·작업 해시·기존 접수가 모두 일치한 과거 접수/완료 충돌만 격리. 원격 불변 결과를 덮어쓰지 않음 |
| 공개 허브 | 반복 중계의 자동 게시 없음. 원격 실행 자체와 공개 기록 전송을 구분 |

## 창과 권한

focus_window는 검증된 hwnd에 대해 한 번만 활성화를 요청하고 최대 400ms 실제 전경 상태를 확인한다.
foreground_activation_denied는 창 활성화 범위의 실패이며 전체 PC 접근 거절이나 앱 관리자 권한 문제의 증거가 아니다.
foreground_window_changed는 예상 전경 창이 달라 입력 전에 멈춘 상태다. 목록을 새로 읽고 입력을 맹목적으로 재전송하지 않는다.
ui_permission_or_desktop_unavailable, host의 명시적 정책 거절, UAC·잠금·상위 무결성 제한은 별도로 확인한다.

좌표·키 입력에는 새로 확인한 expectedHwnd를 넣는다. UIA 변경은 hwnd·요소 ID·정확한 이름·PID·전경 조건을 계속 확인한다.
실패한 포커스 요청을 대화 응답과 함께 반복하거나 사용자에게 계속 클릭하라고 하지 않는다.
대상 UI가 꼭 필요하고 허용된 자동 경로가 모두 불가하면 그 UI 단계만 미완료로 남기고 독립 작업을 진행한다.

## 업데이트와 복구

3.2.2 업데이트 도구는 해시 확인·컴파일·유휴 확인·백업 후 인증된 정상 종료/기존 실행기 재개만 사용한다.
설정·ACL·기기 ID·인증·기존 작업 ID는 변경하지 않는다. 실행 중 작업이 있으면 교체하지 않는다.
이전 버전은 날짜 보관 경로와 복원 대응표를 유지하며 실행 중 프로세스·원본을 나이만으로 삭제하지 않는다.

## 과거 기록의 색인

hot journal은 최근 항목과 작업 메타데이터를 유지하고 오래된 큰 완료 원문은 기존 담당자별 journal에 보존한다.
historyArchive의 SHA-256과 작업·범위 신원을 확인한 뒤 결과를 복원한다. 비일치·누락은 오류이며 축약값을 완료 원문처럼 반환하지 않는다.
예전 실행기로 되돌릴 때는 파일만 덮지 않고 이 색인을 원문 기록으로 복원하는 데이터 호환 절차가 필요하다. 설정·작업 이력을 임의로 이전 스냅샷으로 되감지 않는다.
