# 공용 PC 연결 — 현재 입구

갱신일: 2026-11-18 KST. 현재 코드: [ProjectBridge 3.2.2](releases/20261118-v3.2.2/README.md).
실제 설치·검사 결과는 [검증 기록](releases/20261118-v3.2.2/VALIDATION.json)에서 확인한다.

PC에서 쓰는 입구는 설치 폴더의 **프로젝트연결.exe**, 도구 연결은 **PluginMarketplace의 projectbridge-local**이다.
코드·검사·내부 실행 파일은 Runtime, 실제 설정·진행 기록은 기존 config.json·state를 유지한다.
사용법은 [사람용 안내](../../000_사용자용/02_프로그램/PC_연결과_소통.md), 규약은 [PROTOCOL](PROTOCOL.md)이다.

| 구성 | 구분 |
|---|---|
| 3.2.2 | 현재 유지보수 코드. 창 활성화 실패 범위, 장기 작업 종료 추적, 과거 중계 결과 충돌 격리, 버전 원본과 Windows 백업 경로 보완 |
| 3.2.1 | 플러그인 등록만 고친 과거판. 본체 3.2.0과 기능 버전이 달랐던 이력 |
| 3.2.0 | 이번 수정 전 설치 본체. 파일 존재·기동·기능 사용 성공을 구분 |
| [3.0](releases/20261006-v3/README.md), [2.0](releases/20261006-v2/README.md) | 호환·복구·과거 검증용. 최신 설치 안내가 아님 |

로컬 API 정상과 비공개 GitHub 중계 정상은 별개다. 상태의 localReady, relayConnected, relayCode를 각각 확인한다.
장기 작업은 시작 접수가 완료가 아니다. 같은 작업 ID로 실제 종료 결과를 조회하고 실행 불명일 때 새 ID로 재실행하지 않는다.

창 전환 실패는 PC 전체 권한 거절이 아니다. 브릿지가 포커스를 얻지 못했거나 답장 중 ChatGPT가 앞으로 오면,
목록을 한 번 새로 확인하고 독립적인 파일·API 작업을 계속한다. 수동 클릭을 무한 반복해 요구하지 않는다.
명시적 host 정책·UAC·잠금·인증 거절은 우회하지 않는다. 다른 UI 표면도 이미 허용되고 실제 연결된 경우만 사용한다.

공개 허브에는 선별한 설명·검증 요약만 관리자의 명시적 일회 지시로 보낸다.
반복 PC 중계는 공개 요약을 자동 게시하지 않는다. 구형 공개 오디오북 작업 큐도 기본 실행 루프에서 폐기한다.
비공개 결과·토큰·화면·대화 원문·전체 로그는 공개하지 않는다.

[교체 전 안내 원문](../../99_ARCHIVE/2026-11-18/bridge-docs-before/README.md)은 당시 상태의 보관본이다.
