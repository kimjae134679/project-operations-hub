# 프로젝트 연결 사용 안내

하나의 Windows 연결 프로그램으로 여러 프로젝트의 파일·명령·빌드·설치·화면 작업을 전달하고 결과를 확인합니다. 무직전생뿐 아니라 다른 프로젝트에도 같은 연결을 사용할 수 있습니다. OpenAI API 키가 필요한 프로그램은 아닙니다.

**처음 한 번 PC에 설치·실행하고 GitHub 인증을 확인해야 합니다.** 이후에는 GitHub가 연결된 대화에서 비공개 작업 큐로 요청하고 결과를 읽습니다. PC가 켜져 있고 연결 프로그램이 실행 중이어야 합니다. 아직 실제 설치·연결·화면 조작을 확인하기 전이면 준비된 코드와 PC 적용 완료를 구분해서 봅니다.

| 보고 싶은 것 | 위치·행동 |
| --- | --- |
| 연결 프로그램 | 목표 위치 `D:\A_KJ\AI\Applications\ProjectBridge\프로젝트연결.exe`에서 실행 |
| 최초 설치 방법 | [공개 설치 코드](https://github.com/kimjae134679/project-operations-hub/blob/main/04_COMMUNICATION/remote-bridge/install.ps1)와 같은 배포본의 [README](README.md). 배포 commit과 manifest SHA를 확인 |
| 연결 상태·로컬 작업 기록·백업 | 연결 창의 **기록 폴더**. 프로그램 아래 `state` 폴더 |
| 실제 원격 요청 | 비공개 저장소 `kimjae134679/Mushoku-Tensei-AI-Audiobook` → `remote/pc-bridge` branch → `_pc_bridge/queue.json` |
| 연결된 PC 선택 | 같은 비공개 branch의 `_pc_bridge/devices/<device>.json`에서 실제 장치 ID·마지막 연결·지원 기능 확인 |
| 실제 작업 결과 | 같은 비공개 branch의 `_pc_bridge/results/<device>/<job>.json` |
| 통합소통에 공유한 요약 | 공개 `project-operations-hub`의 프로젝트 소통 기록. 상세 결과는 비공개 작업 채널에서 확인 |
| 각 프로젝트 원본·음원·모델 | 기존 프로젝트 위치. 연결 설치를 위해 옮기지 않음 |
| 전체 운영 규칙 | [공통 PC 연결 규약](UNIVERSAL_PROTOCOL.md) |

비공개 저장소의 이름에 무직전생이 들어가 있어도 이 작업 branch는 PC 공통 연결용입니다. 다른 대화에서 사용하려면 GitHub 연결이 해당 비공개 저장소를 읽고 쓸 수 있어야 합니다. 접근 권한이 없는 대화에서는 공개 통합소통 문서만으로 PC에 명령을 전달할 수 없습니다.

## 연결 창에서 하는 일

- **연결 / 재개**: 요청을 받기 시작하거나 연결 오류 뒤 다시 시도합니다.
- **연결 일시정지**: 새 요청 수신을 멈춥니다. 이미 실행 중인 작업과 PC의 별도 제작 프로그램 상태는 따로 확인합니다.
- **연결 종료**: 현재 실행 작업이 끝나면 연결을 종료합니다. 같은 로그인 중에는 자동 복구하지 않습니다.
- **기록 폴더**: 연결 문제·작업 결과·백업을 확인합니다.

창의 X는 트레이로 접습니다. 완전히 끄려면 트레이의 종료 메뉴를 사용합니다. 로그인 자동 시작을 등록한 경우 다음 Windows 로그인에는 다시 시작합니다. CMD·PowerShell 창을 계속 띄우는 방식으로 자동 실행하지 않습니다. 다른 편집기나 원격 연결을 이 창의 종료와 함께 끄지 않습니다.

## AI가 작업할 때

현재 작업 큐, 실제 장치 기록과 해당 프로젝트의 `프로젝트_사용안내.md`를 먼저 읽습니다. 공통 PC 요청에는 `target: PC`와 실제 장치의 정확한 `deviceId`를 필수로 지정합니다. 파일을 고치거나 프로그램을 실행할 때 기존 작업과 미저장 파일을 확인합니다. 요청마다 새 ID를 쓰고, 같은 ID의 작업을 다시 실행하기 위해 내용을 바꾸지 않습니다. 최신 비공개 결과의 실제 실행 상태·산출물을 확인한 뒤 완료를 보고합니다.

파일 정리·개발·빌드·설치·프로그램 실행·화면 확인은 서로 다른 작업으로 요청하고 검증할 수 있습니다. 지원되는 동작과 필요한 인수는 배포된 worker 규약을 따릅니다. 관리자 승인 화면이나 잠긴 화면은 사용자 도움이 필요할 수 있습니다. 설치됐다는 사실만으로 모든 프로젝트와 화면 조작이 검증됐다고 표시하지 않습니다.

공개 통합소통에는 읽기 쉬운 짧은 결과만 공유합니다. 실제 명령, 로그, 파일 내용, 화면 캡처, 대본, 음원, 비밀값을 공개 문서로 옮기지 않습니다. 다른 AI의 읽음과 적용은 대신 기록하지 않습니다.

## 무직전생 작업을 함께 사용할 때

기존 프로젝트 위치는 `D:\AI\VoiceAudiobook`입니다. 해당 폴더의 `프로젝트_사용안내.md`에서 최신 완성본·제작 중·캐릭터 듣기·비교·원본 표본·이전판을 확인합니다. 연결 프로그램이 원격 요청을 받는 것과 오디오북 제작 큐의 실행은 별개입니다.

이미 실행 중인 제작 큐는 재시작하거나 중복으로 시작하지 않습니다. 먼저 현재 제작 진행을 확인하고, 새로 완성된 음원과 교체된 음원을 청취 목록에 반영합니다. 기존 원본·모델·정상 음원은 정리를 이유로 삭제하지 않습니다.

## 연결이 안 되면

연결 창의 상태와 **기록 폴더**를 확인합니다. GitHub 인증이 필요하면 PC에서 기존 GitHub CLI 또는 Git Credential Manager 로그인을 확인합니다. 토큰을 채팅에 보내지 않습니다. 네트워크가 끊겼거나 PC가 꺼져 있으면 새 작업은 연결이 복구된 뒤 처리됩니다.

실행은 끝났지만 결과 업로드만 실패한 경우에는 결과 전송을 재시도합니다. 파일 수정이나 설치가 이미 실행됐는지 모르는 경우에는 현재 파일과 로컬 결과부터 확인합니다. 실패한 요청을 무조건 다시 실행해 중복 결과를 만들지 않습니다.

이 안내는 설치 목표와 사용 방법을 설명합니다. 실제 PC 설치·로그인 자동 시작·원격 왕복·화면 입력 검증 여부는 배포본의 검증 기록과 실제 결과를 확인해야 합니다.
