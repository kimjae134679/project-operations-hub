# 공용 PC 연결 사용 안내

통합 관리 프로그램의 PC 연결 화면에서 연결 상태와 각 프로젝트·담당자의 작업을 확인합니다. **연결 켜기**, **일시정지**, **연결 끄기**도 이 화면에서 사용합니다. 로그인하면 자동으로 연결을 시작하며, 의도적으로 끄면 이번 로그인 동안 꺼진 상태를 유지합니다.

설치 폴더의 `프로젝트연결.exe`는 필요할 때 연결 창을 여는 입구입니다. 평소에는 별도 CMD·PowerShell 창이나 실행 창을 띄우지 않습니다. 내부 실행 파일은 숨김 `Runtime` 폴더에 모아 두었습니다. 설정·진행 중인 작업·로그는 원래 경로를 유지하므로 직접 옮기지 않아도 됩니다.

독립 작업은 동시에 실행합니다. 같은 파일이나 화면 입력이 겹치면 차례로 처리합니다. 프로젝트와 명령을 보낸 담당자의 작업 폴더와 기록도 따로 관리합니다. 상세 기술 안내는 설치 폴더의 `Runtime/README.md`와 `Runtime/UNIVERSAL_PROTOCOL.md`에 있습니다.

장기 작업은 **시작 접수 → 실행 중 → 실제 종료 결과**를 구분합니다. 시작했다는 이유만으로 성공 처리하거나 다음 단계를 실행하지 않습니다. 공유 자원은 종료까지 예약하며, 실제 성공한 작업만 다음 단계로 이어집니다. 실패·시간 초과·중지·중단이면 후속 작업은 실행하지 않고 확인 필요로 남깁니다. 연결 프로그램을 재시작해도 등록된 작업을 다시 시작하지 않고 상태 확인을 이어갑니다. 자기 작업의 상태 조회·중지는 실행 중인 자원 예약 때문에 막히지 않습니다.

파일 이동과 보관 삭제는 대상 파일의 현재 내용이 확인된 경우에만 실행합니다. 보관 삭제한 파일은 같은 프로젝트·담당자가 복구할 수 있고 기존 파일을 덮어쓰지 않습니다. 폴더 전체 재귀 삭제는 지원하지 않습니다. 바탕화면과 보호 경로는 수정하지 않습니다.

로컬 연결과 원격 GitHub 중계는 별도로 표시됩니다. 설치 완료 표시만으로 원격 연결 성공을 뜻하지 않습니다. 기존 오디오북 작업은 연결 설치 때문에 다시 시작하지 않습니다.

설치 중 `config_writealltext_attribute_conflict_before_install`이 표시되면 기존 설정 파일의 Hidden(숨김)·System(시스템) 속성과 후속 쓰기 방식이 충돌할 수 있어 안전하게 멈춘 것입니다. 설정 내용·속성·접근 권한과 실행 중인 연결은 이 사전 검사로 변경되지 않습니다. 자동 속성 제거·권한 변경이나 같은 설치의 무작정 재시도는 하지 않습니다. 이 방어 코드는 운영 설치 완료나 이전 오류의 원인 확정과 구분합니다.
