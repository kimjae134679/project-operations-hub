# 프로젝트 연결 사용 안내

현재 유지보수판: 3.2.2 · 2026-11-18 KST.
설치 폴더의 프로젝트연결.exe가 사용자 입구이며 내부 파일은 Runtime에 있다.
로컬 도구 연결과 비공개 원격 연결은 별도 상태다. 설치·접수·실제 완료를 구분한다.

창을 앞으로 가져오지 못했을 때 같은 클릭 요청을 반복하지 않는다. AI가 파일·API 등 가능한 작업을 먼저 이어 간다.
브릿지는 Windows의 창 전환·잠금·UAC 제한을 해제하지 않는다. ChatGPT 앱의 도구 승인 설정도 별도다.

기존 작업·인증·설정은 그대로 유지하며 구버전 자료는 날짜 보관 위치에서 복구할 수 있다.
오래된 README의 2.0/3.0 진행 상태를 현재 상태로 해석하지 않는다. 현재 확인은 Runtime/VALIDATION.json과 실제 상태 조회를 따른다.
