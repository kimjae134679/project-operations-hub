# 변경 기록

## 0.6.0 — 2026-10-06
- 선택된 디자인 예시 2·6·7·8을 반영한 고정 프로젝트 목록, 겹친 작업면과 기능별 작업 카드.
- 밝은/어두운 화면 전환과 저장; 본문·상태·버튼·선택·드롭다운·공지·AI 전달 창을 함께 전환.
- 긴 한글 이름과 가상화 프로젝트 목록, 작은 창의 공지·실행 버튼 공간 개선.
- 작업 선택란의 내부 클래스명 표시 수정, 실제 렌더링 대비·테마 왕복·200개 프로젝트 검색 검증 추가.


## 2026-10-05 — 0.3.0

- 먹색 화면과 라임 강조로 전면 개편했습니다. 한글 이름·실제 행동을 유지하고 공지 표와 경로를 네이티브 문서로 읽습니다.
- ‘공지사항’과 ‘프로젝트 소통’을 앱에 추가했습니다. 실제 프로젝트의 `_통합소통`에서 공지 배포, 본인 확인 기록·보낼 자료 수집, 전용 저장소를 통한 GitHub 동기화를 반복합니다. 앱 종료·오프라인은 다음 연결에서 이어갑니다.
- 파일 해시·내용 변경·소유자·실제 경로를 검증하고 동일 자료를 중복 수집하지 않습니다. 자동 전달을 AI의 읽음·적용 기록으로 만들지 않습니다.
- ‘멀티의 신 서버’에서 로컬 집계 API의 접속·준비·플레이 인원과 서버 정책을 확인합니다. 개발 코드와 배포 저장소를 구분하고 서버 실행 폴더에도 공지를 연결합니다. 상태가 바뀔 때만 집계 요약을 보낼 자료에 저장합니다.
- 기존 관리창의 제어 스크립트와 실제 실행 서버 버전이 달라 시작·종료·재시작은 연결을 맞출 때까지 제공하지 않습니다. 실행 중인 서버를 변경하지 않습니다.
- 내부 빌드·소통 저장소를 프로젝트 탐색에서 제외하고 검증 설정을 운영 설정에 저장하지 않습니다.
- 검증 결과는 [자동 소통·서버 검증 기록](docs/VERIFICATION-AUTOMATION-20261005.md)에 기록합니다.

## 2026-10-05 — 0.2.0

- 도구 상태 대시보드를 한국어 이름·용도·폴더 역할로 이해하는 `내 프로젝트`와 보조 `연결·관리` 화면으로 전면 개편했습니다. 따뜻한 회백색·흰색·남색·파랑 테마를 사용합니다.
- 확인한 폴더를 6개 프로젝트, 24개 프로그램·자료 항목으로 묶는 소개 카탈로그를 추가했습니다. 이전 개발본·테스트 사본·복구 자료는 관련 프로젝트 안에 표시하며 원본 폴더를 이동·삭제하지 않습니다.
- 프로젝트·프로그램 검색, 기능별 목록, 항목 소개와 실제 행동을 연결했습니다. 폴더 위치·작업 기록·개발·보관 기능은 기본 접힘이며 검색 결과의 기능은 펼칩니다.
- 자료 열기와 명령 실행을 구분했습니다. 휴대폰 APK·용도 미확인 EXE는 위치를 보여주고 자동 실행하지 않습니다. 등록 명령이 있는 항목만 실행·중지하며 이미 응답하는 로컬 제작 화면은 재사용합니다.
- 확인된 Unity 편집기는 기존 열기 스크립트로 연결하고 중복 열기를 방지합니다. 편집기의 미저장 작업은 관제탑 종료·중지 대상에서 제외합니다.
- 프로젝트별 실행 잠금, 최대 3개 작업, Windows Job Object를 통한 소유 작업과 자식 프로세스 관리, 실제 종료 코드와 로그 기록을 추가했습니다.
- 원격 연결의 시작 등록을 통합하고 기존 연결을 재사용합니다. 현재 연결을 임의 종료하지 않습니다. 화면에는 한국어 이름·용도를 표시하고 n8n·GPT 전달 상태는 사용자 목록에서 제외합니다.
- Jev 선택 사용과 실제 작업 전달을 연결했습니다. 과거 TXT 큐와 중단된 작업은 자동 재실행하지 않습니다.
- 단일 앱 실행, 네이티브 라이브러리를 포함한 단일 EXE 배포, 사용자 데이터·로그·공유 연결을 보존하는 제거를 반영했습니다.
- Windows 테스트 36개 통과. 실제 WPF 캡처, 검색·작은 창 조작 경계, `.NET --version` 실행과 최종 배포 근거는 [검증 기록](docs/VERIFICATION-20261005.md)에 기록합니다. 게임·GPU 제작·다운로드·Jev 인증 왕복은 이번 검증 범위에 포함하지 않습니다.
