# 작업 중심 UI · 독립 미리보기

이 변경은 실행 중인 0.9.11.0을 기준으로 만든 별도 UI 소스와 미리보기입니다. 운영 앱 교체·설치·시작프로그램 변경은 하지 않았습니다.

## 사용하는 순서

1. 왼쪽 **내 프로젝트**에서 실제 등록 프로젝트를 고릅니다.
2. **만들기·제작물**에서 등록 항목을 고릅니다. 오른쪽 위 **파일·폴더 보기**는 실제 연결된 원본을 엽니다. 명령 또는 편집기 실행기가 등록된 항목에는 기존 실행 버튼이 표시됩니다.
3. **작업 목록**에서 제목·상태를 검색하고 프로젝트·상태를 고릅니다. 오른쪽에서 현재 단계, 다음 할 일, 결과와 오류를 확인합니다. 실행기·명령·원본 경로 등은 **실행 정보·내부 기록**을 펼쳐 봅니다.
4. **단계 현황**은 기존 관리자 프로젝트 기록을 같은 방식으로 보여 줍니다. **PC 연결**의 기존 기능과 내용은 유지됩니다.

**예약 일정은 미지원**입니다. 시간 예약, 새로운 계정 카드, 생성되지 않은 제작물·성과·완료율은 만들지 않습니다. 작업 목록의 진행·완료 표시는 실제 기록의 상태이며 현재 프로세스 생존이나 프로젝트 전체 완료를 대신하지 않습니다. 생존 확인이 없는 running 기록은 상태 필터의 **오류·중단·확인 필요**에 포함됩니다.

Threads 제작물 보기·리뷰 열기·편집·원본·보류 등은 수익화 담당자가 등록한 실제 항목과 해당 앱을 통해 사용합니다. 이번 변경은 공통 메뉴·작업 목록·기존 행동을 개선하며 Threads 실행 파일·리뷰 데이터·catalog를 수정하지 않습니다. 기준 소스에 없는 진입점을 임의로 추가하지 않았습니다.

## 미리보기와 운영의 구분

PC에 별도 생성한 `ui-actions-20261008/preview/START_UI_PREVIEW.vbs`는 사용자가 직접 열 때만 `AIControlTower.exe --local-view`를 실행합니다. 사용자가 조회 창에서 선택·검색·화면 이동을 검토할 수 있습니다. 로컬 조회 모드는 기존 운영 창과 별도 경계이며 등록 명령·외부 상태 조회·설정 저장·원격 제어를 허용하지 않습니다. 다른 실행 인수를 섞지 마세요.

빌드만 재현하려면 .NET 9 Windows 환경에서 다음 명령을 실행합니다. 설치·운영 앱 실행 명령이 아닙니다.

```powershell
dotnet publish ai-control-tower/src/AIControlTower/AIControlTower.csproj -c Release --self-contained false -p:PublishSingleFile=false -o "$env:TEMP/HubActionPreview"
```

미리보기 실행 파일의 버전은 기준 소스의 0.9.11을 유지합니다. 운영 버전보다 새 버전으로 설치됐다는 뜻이 아닙니다. 실제 사용 승인과 별개로 이번 작업에서는 창을 띄우거나 운영 앱을 종료하지 않았습니다.

## 검증과 남은 범위

- 새 상태 필터의 실패→통과, 선택 보존·교집합·관측 가능한 개수·중단 호출 없음 검사.
- 기존 창 표시 테스트 `MouseWheelRoutingTests`를 제외한 전체 검사. 나머지 테스트는 실제 WPF 리소스·컨트롤 렌더링을 포함합니다.
- 작업 카드·상태 배지의 작은 화면 경계와 조회 실패의 가시성 회귀 검사.
- 별도 in-memory WPF 호스트로 1460×900 / 1060×720, 밝게/어둡게의 프로젝트·작업 화면 및 검색 결과 없음 렌더링. 실제 로컬 기록만 읽었으며 가짜 기록을 사용하지 않았습니다. 네이티브 창 표시 0회, 운영 초기화·외부 조회·명령 실행 0회.
- PC 연결 XAML과 보호된 브릿지·시작 경로의 변경 없음 검사, `git diff --check`, Release 빌드, 원격 브랜치 SHA 확인.

첨부 참고 이미지 4개의 Library 다운로드는 현재 transfer helper에서 HTTP 403으로 차단되어 픽셀을 확인하지 못했습니다. 우회·반복 다운로드하지 않았으며 요청된 작업 흐름 설명을 적용했습니다. 구현한 화면의 실제 픽셀 검수와 참고 이미지 검수는 구분합니다.

로컬 QA 이미지·작업 기록·실행 파일은 PC의 독립 작업 폴더에 보관합니다. 실제 사용자 데이터가 담긴 이미지를 공개 저장소에 올리지 않습니다. 상세 검사 결과는 [검증 기록](UI-ACTIONS-20261008.json)을 확인하세요.
