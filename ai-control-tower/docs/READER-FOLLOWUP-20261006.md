# 소통방·도구·프로젝트 안내 후속 수정

사용자는 초록색 위주 화면과 버튼, 한 글자 프로젝트 배지, 좁은 소통 본문과 매초 회전하는 갱신 표시를 수정하고 원격 데스크톱·Jev 등 전체 도구를 찾을 수 있게 하라고 요청했습니다. 각 프로젝트 담당자가 실제 자료 위치와 설명·필요한 이미지가 있는 안내를 작성하고 AI가 이를 먼저 읽도록 하는 방식도 요청했습니다.

## 작성한 소스

- 밝음·어두움 팔레트를 중립 회색·흰색과 제한된 파란 강조색으로 변경. 버튼 받침·위치 튀김 제거, 키보드 포커스 유지.
- 한 글자 배지를 제거하고 프로젝트 이름에 폭을 사용.
- 소통방은 프로젝트 선택·검색 위에, 글 목록과 넓은 본문 아래에 배치. 제목·상태·본문을 같은 RichTextBox 문서에서 함께 스크롤. JSON 원본은 펼쳐 읽고 복사.
- 도구 표시 필터를 제거하고 Remote Desktop Commander/Jev/Codex의 제품명 표시. n8n, Aider, HyperFrames, MoneyPrinterTurbo, VoiceStudio, Zonos2도 표시. 등록 위치/PATH의 파일 확인과 실제 실행 성공은 구분.
- 기본 자동 조회 5초, 선택 1/3/5/10/30초. 자동 조회 중 회전·짧은 조회 문구 반복 없이 목록 갱신. 수동 갱신은 진행한 한 바퀴를 마치고, 회전은 800/1200/1800/2400ms 선택. 설정 저장.
- 프로젝트의 현재 안내를 읽는 탭·버튼. Markdown/TXT 원문 유지, 실제 존재하는 오디오·영상·문서·폴더 링크와 로컬 설명 이미지 지원. 안내가 없으면 미작성 표시. 원본·모델·음원을 이동하지 않음.
- 안내가 동일하면 문서와 스크롤 유지, 알려진 검증 임시 폴더는 발견에서 제외.

## 수행한 확인

- Python 공지·기록 도우미 테스트 29개 통과.
- 공지 manifest와 본문 SHA-256 검증 통과.
- XAML 3개 XML 구문 확인, 변경 공백 검사 통과.
- 기존 대비 검사와 같은 배경/본문/선택/레이일/버튼 조합·그라데이션의 정적 계산: 밝음 최소 5.8313:1, 어두움 최소 6.4383:1. `reader-static-verification.json` 참조. 실제 화면 측정은 아님.
- 독립 읽기 전용 코드 검토에서 확정된 중요 오류 없음. 빌드·실행 검증은 아님.
- 안내 보존·한글 링크·미확인 위치·실행 스크립트 제외·큰 안내·설정 경계 C# 테스트 5개 추가. **실행하지 않음**.

## 막힘과 다음 작업

KJW Desktop Commander는 목록에 등록돼 있으나 ping 결과 오프라인입니다. 원격 명령은 시간 초과했고 PC의 현재 소스·설치본·오디오북 공지 폴더 권한 오류는 확인하지 못했습니다. Scratch에는 .NET SDK가 없어 WPF 빌드·Windows 테스트도 수행하지 못했습니다.

이전 대화에서 언급한 0.6.1 이후 로컬 작업(안내 9개 등)은 GitHub main에 없습니다. PC 연결 후 **git status·현재 branch·diff·기존 안내 파일을 먼저 확인하고 보존**합니다. 이 변경을 미게시 로컬 수정본 위에 덮어씌우지 않고 겹치는 구현을 비교해 통합합니다. 실제 PC 자료 안내와 링크 존재를 다시 확인합니다.

이후 Windows에서 테스트·publish, 1060×720/1460×920 밝음·어두움 확인, 긴 제목·본문 끝까지 스크롤, 원본 펼침, 자동 탐색 중 안내 스크롤 유지, 이미지·음원 링크, 자동/수동 회전과 속도 옵션을 검증합니다. 오디오북 소통 폴더 권한 오류를 재현해 수정한 뒤 기존 앱을 백업하고 설치본을 교체합니다. 중앙 기록과 실제 PC 수집·N-0008 전달 여부도 별도로 확인합니다.

이번 소스는 미검증 작업 브랜치로 남깁니다. 설치 완료·기존 로컬 작업 복구 완료·다른 AI 안내 작성 완료로 표시하지 않습니다.
