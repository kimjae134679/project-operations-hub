# 컨트롤타워 화면 재설계 · 2026-10-05

사용자가 먹색·라임 화면과 기존 디자인 자체를 거부했다. 새 화면은 따뜻한 밝은 작업 공간, 작은 잉크색 탐색 영역, 절제한 코발트 행동 색을 사용한다. 선택 프로젝트를 큰 제목과 목적 문장으로 소개하고, 프로젝트 선택과 실행 행동을 서로 다른 영역에 둔다. 기존 표의 색·모서리만 바꾸는 방식으로 완료하지 않는다.

이 문서는 디자인 참고와 구현 제안이다. 아래 수치는 우리 화면의 제안값이며 참고 사이트에서 측정한 값이 아니다. 실제 WPF 화면 구현·작은 창·작동 검증은 별도다. 이 문서 작성에서 XAML·기능·프로젝트 원본을 수정하지 않았다.

## 화면의 새 구조

넓은 창에서 왼쪽은 **작은 탐색**, 중앙은 **선택 프로젝트 소개와 프로젝트 고르기**, 오른쪽은 **바로 하기**로 나눈다. 흰 작업 면 전체를 작은 대시보드 카드로 채우지 않는다.

1. 왼쪽 잉크색 영역에는 작은 `통합소통방` 이름, `프로젝트`, `공지와 기록`, `도구`를 둔다. 글자와 아이콘을 함께 사용하고 아이콘만으로 뜻을 추측하게 하지 않는다. 현재 위치 한 항목만 강조한다.
2. 중앙 위에는 현재 선택 프로젝트의 큰 한국어 이름, 실제 목적 한 문장, 확인한 상태와 주 행동 하나를 둔다. 큰 테두리 상자 대신 밝은 바탕 위의 열린 제목 영역으로 만든다. 모든 프로젝트에 같은 홍보 문구를 붙이지 않는다.
3. 그 아래에는 짧은 검색·필터와 **두 열의 선택 카드**를 둔다. 카드에는 프로젝트 이름, 목적 두 줄 이내, 종류·현재 상태를 담는다. 카드 전체는 선택 행동이고 실제 프로그램 실행은 별도 버튼이다. 실행·중지·경로·정책 버튼을 카드마다 반복하지 않는다.
4. 오른쪽의 좁은 흰 패널은 중앙 목록을 스크롤해도 유지한다. 선택 프로젝트 이름과 `바로 하기`, 실제 지원하는 행동, 관련 자료·위치 순으로 둔다. 긴 경로와 지난 자료는 접어서 펼친다. 행동이 많으면 패널 안에서 따로 스크롤한다.
5. 마지막 동기화와 남은 보류는 작은 하단 상태 영역에 실제 값으로 표시한다. 실측 서버 숫자는 서버 화면에서 보여주며 일반 프로젝트 선택 화면의 장식 지표로 반복하지 않는다.

초기 중앙 제목의 예시는 `멀티의 신`이며 목적 문장은 실제 카탈로그에서 가져온다. 오른쪽에는 검증된 연결에 따라 `Unity 열기`, `주 작업 폴더 열기`, `저장소 보기`, `안내 읽기` 등이 나타난다. 휴대폰 설치파일은 `휴대폰 설치파일 보기`로 구분한다. 파일 존재만으로 `설치 완료`, `실행 중`, `정상 연결`을 표시하지 않는다.

폰트는 실제 PC에서 확인한 기본 Windows 글꼴과 한글 대체 글꼴을 사용한다. 새 글꼴 설치가 디자인 완료 조건은 아니다. 얇은 작은 글자·긴 영문 제목·과한 자간으로 분위기를 만들지 않는다. 제안 색상은 구현 후 실제 배경과 글자 조합의 대비를 확인해야 하며, 참고 이미지가 접근성을 검증했다는 뜻은 아니다.

## 작동 상태와 작은 창

- 프로젝트 선택: 파란 얇은 경계·작은 선택 표시·아주 옅은 바탕 변화로 동시에 표현한다. 카드 전체를 파란 단색 면으로 뒤집지 않는다.
- 마우스 이동: 경계나 바탕을 조금 바꾸며 키보드 포커스도 같은 정도로 분명하게 보인다. 소리·반복 발광·과한 그림자·확대 애니메이션은 기본 동작에 넣지 않는다.
- 작은 창: 먼저 카드가 한 열로 바뀌고 중앙 여백이 줄어든다. 오른쪽 행동 영역을 좁혀 글자를 자르기보다 현재 프로젝트 제목 아래의 행동 영역으로 옮기는 방향을 검토한다. 기존 기능은 스크롤·접힘으로 접근할 수 있어야 한다.
- 긴 이름·경로: 한국어 이름은 줄바꿈을 허용한다. 카드 목적은 두 줄 안에 읽히게 하되 전체 설명을 펼쳐 볼 수 있다. 실제 경로는 기본 화면을 밀어내지 않게 상세에 둔다.
- 미확인·실패·대기: 문장과 아이콘으로 구별한다. 회색 점이나 색만으로 구별하지 않는다. 서버 조회 실패는 `접속 현황 미확인`이며 0명이 아니다. 로컬 수집과 중앙 공유 완료도 별개다.

## 완료 판단

새 화면은 선택 프로젝트의 의미와 다음 행동이 먼저 읽혀야 한다. 기존 화면과 비교해 제목 위계·영역 배치·목록 선택·행동 위치가 모두 달라야 한다. 색 변경만으로 완료하지 않는다.

실제 앱에서 일반 크기·최소 크기, 긴 한글 이름, 준비 폴더, 서버 조회 실패, 중앙 동기화 대기, 프로그램 선택과 실행 버튼을 확인한다. 공지 본문·확인 기록·자료 수집·서버 실측·작업 중지 등 기존 기능은 그대로 접근할 수 있어야 한다. 가짜 통계·진척도·수입·장식 차트·영어 배너로 빈 곳을 채우지 않는다.
