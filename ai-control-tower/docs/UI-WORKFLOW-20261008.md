# 프로젝트 작업 흐름 · 독립 UI 미리보기

기존 내 프로젝트·만들기·제작물·작업 목록을 이어서 개선했습니다. 설치된 0.9.11.0과 브릿지는 교체·종료·재시작하지 않습니다. 이 문서의 소스·검사·미리보기와 운영 적용을 구분합니다.

## 먼저 사용하는 순서

1. 왼쪽 프로젝트 검색으로 프로젝트를 고릅니다. 첫 화면에서 연결된 기록 수, 완료 기록, 대기·확인 필요, 최근 결과 기록과 변경을 확인합니다. 관리 프로젝트는 **관리 기록** 범위입니다.
2. **현재 결과 선택** 또는 **리뷰 선택**으로 기존 등록 항목을 고릅니다. 목록은 선택한 카드로 이동하고 오른쪽에 열기 버튼을 보여 줍니다. 바로가기 자체는 프로그램을 실행하지 않습니다. 미등록 리뷰는 **리뷰 미연결**로 표시합니다.
3. **대기·문제**는 같은 프로젝트·같은 범위의 작업 목록을 엽니다. **최근 변경**은 기존 작업·세션으로 이동합니다. 제목·결과·오류·다음 할 일 검색과 프로젝트/상태 조건을 조합하고 **조건 초기화**로 돌아옵니다.
4. 검색 때문에 현재 읽던 프로젝트·작업을 잃지 않습니다. 새 항목을 선택하면 내용이 바뀝니다. 안내·파일 위치·명령·기술 기록은 접힌 영역에서 확인합니다.

**기록의 완료 수는 제작 완료율이 아닙니다.** 실제 제작 metadata가 연결된 경우에만 해당 수량·마지막 기록을 표시하며, 오래된 기록과 현재 실행 확인 필요를 함께 표시합니다. 조회 전·결과 기록 없음·조건에 맞는 기록 없음·읽기 실패·일부 읽기 실패는 구분합니다. 읽기 실패 때 남아 있는 자료는 이전 조회 자료라고 표시합니다. 시간 예약은 여전히 미지원입니다.

Threads의 기존 등록 평가 실행기 0.3.19와 review-only 인수는 유지합니다. 평가·메모·원본·보류 데이터는 수정하지 않았습니다. 오디오북의 결과 항목은 사용자가 지정한 회사 청취용 검증본 폴더에 연결합니다. 폴더 선택은 자동 재생이나 전체 품질 승인을 뜻하지 않습니다.
