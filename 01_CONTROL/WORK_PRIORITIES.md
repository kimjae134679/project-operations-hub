# 현재 작업 우선순위

정리일: 2026-11-12 KST. 현재 사용자 요청이 과거 계획보다 우선한다.

## 현재 승인 범위
- 핵심 스킬 4개(agent-desktop·오류 조사·완료 검증·UI 개선)와 앱 재현 단계 11개를 필요한 작업에서만 사용한다.
- replica는 복구해 앱 재현 맥락의 해당 단계에 선택하고, 일반 개발·URL만 있는 질문에 클론을 시작하지 않는다.
- 추가로 제외한 10개 절차는 원래 설명·그림·스크립트와 함께 날짜 보관한다.
- PC 파일·설정·명령은 우리 ProjectBridge 우선, 허가된 앱 UI는 현재 host가 허용하는 agent-desktop/대안 CUA를 사용한다.
- 분류·날짜·설명·첨부·보존은 [통합소통 기록 규칙](../04_COMMUNICATION/RECORDING_RULES.md) 한 곳에서 관리한다.
- 사용자는 선별한 스킬·설명·비민감 이미지·정책의 일회 GitHub 동기화를 승인했다. 상시 자동 전송·전체 계정 설치 승인이 아니다.

## 완료와 후속 판단
- 로컬 구성, 공개 자료 준비, commit·push·PR·병합은 별도 결과다. 업로드 성공을 미리 쓰지 않고 실제 최종 commit/PR을 근거로 판단한다.
- 현재 작업이 끝나도 과거 Threads·오디오북·다른 프로젝트의 큐를 자동 실행하지 않는다.
- 재개 요청이 오면 현재 자료·기존 실행·dirty·실제 완료 여부를 대조하고 기존 제작·미저장 작업을 보호한다.
- Vane의 재부팅·Docker·Vane 준비 미완료는 별도 상태다. 이번 규칙 정리를 이유로 재부팅·후속 설치를 시작하지 않는다.
