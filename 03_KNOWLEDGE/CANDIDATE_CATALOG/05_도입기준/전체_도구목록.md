# 전체 도구 목록 · 현재 선택 기준

**재분류: 2026-11-03 KST.** 이전 상세 조사의 HIGH-FIT·순위는 당시 참고이며 현재 추천이 아닙니다. 유용한 소수만 남긴 현재 입구입니다. [채택 원본](../../../01_CONTROL/TOOLS.md) · [설치 증거](../../../01_CONTROL/AI_INSTALLATIONS.md).

## 후속 실제 설치 상태가 우선

초기 조사 후 사용자가 **설치**를 다시 명시했습니다. Replica 11개 + Windows Skill 1개은 실제 설치/네이티브 enabled 인식, Apify 0.20.0은 `apify-docs` 등록·토큰 없는 문서 도구 2개 연결·공식 문서6,456자 조회를 확인했습니다. OpenMausBot 0.1.138 portable도 실제 설치하고 D 데이터/기존 Codex/gpt-6.1-sol 정상 수동 시작을 준비했지만 GUI·로그인·모델 응답은 미검증입니다. [설치/실행 안내](../../../000_사용자용/02_프로그램/사진도구_설치와_실행.md). 이 상태가 기존 접근표의 미연결·미설치 판단보다 우선하며 Actor 수집/다른계정 도구는 여전히 별도입니다.

## 현재 추천/설치 목록에서 제외한 과거 참고

아래는 **활성 후보·순위·설치 대기열이 아닙니다**. 기존 조사·원문은 역사적 근거로만 보존합니다.

- 기억 중복: OpenViking/Mem0/Supermemory/LlamaIndex/RAGFlow. Engram/허브의 실제 검색 실패 없이 추가 안 함.
- Agent/관제 중복: CrewAI/AutoGen/MetaGPT/LangGraph/Task Master/OpenHands/Hermes/OpenClaw/AutoGPT. 현재 Codex/관제/연결로 못 푸는 구체적 문제 없이는 도입 안 함.
- 전역 지침 묶음: ECC/추가 Superpowers 전체/Vercel Skills 대량 설치. 필요한 개별 지침만 참고, hook/rules/MCP 덮어쓰기 안 함. Replica는 후속 지시로11개를 실제 설치했으며 기존 지침을 덮지 않고 앱 재구현 요청에 선택합니다.
- 모델/서버: Dify/Langflow/LobeHub/LibreChat/Open WebUI/Ollama/llama.cpp/vLLM/Transformers/OpenLLM/BentoML/xFormers/cuML/DeepSeek. 실제 프로젝트 요구 없이 다운로드/운영 안 함.
- 학습/발견용: Anthropic/Scientific/Agency/Awesome Skills, public-apis/gitignore/build-your-own-x/roadmap·책. 설치 대상 아님. Bumblebee는 Windows 보안툴로 채택 안 함, iFixAi는 원본 미확인.
- OpenMausBot는 이 제외 목록이 아니라 위의 **설치됨/수동 시작 준비·실행미검증** 상태입니다. 선택형 cloud/계정 연결·상시 운영은 하지 않았습니다.
- Bytebot: 공식 저장소 2026-03-07 archived, 신규 설치 제외.

ComfyUI는 요청대로 목록에서 제거했습니다. 로컬 앱·모델·데이터 삭제는 하지 않습니다.

## 실무 순서와 경계

**기존 도구 확인 → 필요한 파일만 읽기 → 최소 변경 → 해당 검사 → diff → 필요한 build/test → 실행/미실행 구분 기록.** 새 결제·유료 API·구독·공개 endpoint·autostart 없이 진행합니다. OAuth/UAC/CAPTCHA가 필요한 연동은 대기합니다. 무료 소스코드 ≠ 무료 모델/클라우드/수집 사용량.
