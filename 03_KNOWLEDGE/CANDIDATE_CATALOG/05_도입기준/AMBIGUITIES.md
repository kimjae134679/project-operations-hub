## `agent-skills`

사용자가 적은 `agent-skills`는 특정 저장소 URL이 붙지 않은 일반명이라 GitHub에 동명/유사 저장소가 여러 개 존재합니다.

이번 카탈로그에서는 **Claude Code Skill 구조 참고용 공식 원본**으로 `https://github.com/anthropics/skills`와 `https://agentskills.io/`를 우선 연결했습니다.

하지만 이것이 사용자가 본 SNS 게시물의 정확한 `agent-skills` 저장소라고 단정하지 않습니다. 확인된 다른 후보에는 HashiCorp, NVIDIA 및 여러 community `agent-skills` 저장소가 있습니다.

정확한 원문 GitHub URL을 나중에 확보하면:
1. 기존 Anthropic 항목을 덮어쓰지 않고 별도 후보로 추가
2. 원래 게시물 설명과 실제 README 비교
3. Skill 종류/지원 Agent/설치방식/라이선스/trigger 범위를 다시 기록
합니다.
