# 도구 사용·접근 모델

**2026-11-03 재정리.** 중복된 과거 연결표는 제거하고 [사용/도움 조건 원본](USAGE_AND_ASSISTANCE.md)으로 연결합니다. 이전 대화에서 도구가 보였다는 이유로 현재 READY라고 하지 않습니다.

1. [현재 작은 목록](전체_도구목록.md)에서 목적에 맞는 도구를 고릅니다.
2. [TOOLS](../../../01_CONTROL/TOOLS.md)에서 채택 범위를 확인합니다.
3. [AI_INSTALLATIONS](../../../01_CONTROL/AI_INSTALLATIONS.md)에서 실제 설치·버전·검사 증거를 확인합니다.
4. 현재 세션의 도구 노출·인증·대상 권한이 확인된 범위만 READY로 기록합니다.
5. 기능 실행과 사용자 흐름 완료는 각각 증거가 필요합니다.

`문서 확인 → 설치 확인 → 현재 연결 → 기능 실행 → 사용자 흐름 완료`는 별개입니다. help/version 성공은 화면·업무 성공이 아닙니다. 계정/OAuth/UAC/CAPTCHA·새 비용이 필요한 연동은 대기합니다. 잠금/UAC 우회·보안 완화·자동 과금 전환·대량 서버/모델 설치는 하지 않습니다.
