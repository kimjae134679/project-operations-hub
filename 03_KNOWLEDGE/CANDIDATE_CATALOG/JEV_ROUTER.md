# Jev Router

## 현재 판단

사용자는 이 작업에서 Jev 사용을 허용했습니다. 필수 사용이나 추가 결제 허가는 아닙니다. 현재 PC에서 `jev-router@0.2.0`, CLI 진입점, 관련 키의 존재를 확인했습니다. 키 값은 읽거나 기록하지 않았습니다. Codex의 ChatGPT 로그인도 확인했습니다. Jev의 실제 인증·모델 선택·작업 왕복과 비용 절감 효과는 아직 검증하지 않았습니다.

| 구분 | 확인 결과 |
|---|---|
| 설치 | npm 전역 위치 `C:\Users\user\AppData\Roaming\npm`, `jev-codex.cmd`, `jev-claude.cmd` |
| 현재 사용 허가 | 있음; 필요한 작업에 선택적으로 사용 |
| 키 | 존재 확인; 값 비공개 |
| 실제 라우팅 성공 | 미검증 |
| 비용 | 경로·모델·계정에 따라 확인 필요; 추가 결제를 자동 승인하지 않음 |
| 관제탑 | 설정에서 선택 활성화; 명령 실행과 결과 기록 지원. 설치를 연동 성공으로 표시하지 않음 |
| 설치·운영 부담 | 로컬 패키지는 🟢; 외부 모델과 인증 관리 부담은 별도 |

## 용도와 비교 방법

단순 작업과 복잡한 작업이 섞이고 모델 선택의 이득이 예상될 때 직접 Codex 실행과 비교합니다. 완료 시간, 결과 품질, 재시도, 전체 사용량을 함께 기록합니다. 라우터를 붙여 대기나 오분류가 늘면 직접 실행이 더 적합할 수 있습니다. 특정 절감률을 측정 없이 약속하지 않습니다.

Jev는 모델 요청 라우터이며 프로젝트 폴더 발견, 프로세스 소유권, 공유 원격 연결 관리와 결과 검증을 대체하지 않습니다. 과거에 찾은 도구라는 이유로 고정하지 않고 현재 공식 문서·호환성·더 나은 대안을 다시 확인합니다.
