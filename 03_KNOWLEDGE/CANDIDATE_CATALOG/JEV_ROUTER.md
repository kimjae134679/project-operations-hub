# Jev Router

확인 기준: 2026-09-19

## 요약

`jev-router`는 Codex/Claude 계열 요청 앞에서 모델 등급을 선택하는 라우터 성격의 도구다. 현재 로컬 PC에는 `jev-router@0.2.0`이 npm 전역 위치에 설치되어 있으나 API key가 설정되지 않아 실제 라우팅은 검증되지 않았다.

## 사용자 정책 기준 분류

| 축 | 상태 |
|---|---|
| ① 현재 바로 쓸 수 있는지 | 아니오 — API key 미설정, 실제 왕복 미검증 |
| ② ChatGPT/연결 서비스라 설치 없이 쓸 수 있는지 | 아니오 — 로컬 CLI 별도 설치형 |
| ③ AI가 사용자 도움 없이 설치·설정할 수 있는지 | 설치는 가능했으나 API key/결제 승인은 사용자 필요 |
| ④ 핵심 기능 AI 단독 운용성 | `1회 준비 후 가능` 예상 / 실제 미검증 |
| ⑤ 사용자 1회 도움 | 필요 — API key 발급·비용 승인·지출 한도 설정 |
| ⑥ 사용자 GUI 필요 | 평상시 CLI 운용에는 불필요, 키 발급/계정 단계는 필요할 수 있음 |
| ⑦ 주 사용자 | AI용 |
| ⑧ 실제 설치/채택 | 설치됨 / 비활성 / 미채택 |
| ⑨ 설치·운영 부담 | 🟢 가벼움(로컬 패키지 기준) |
| ⑩ Cloud/self-host | 로컬 router는 가벼움. 실제 모델 호출은 외부 서비스 의존 |
| ⑪ 보안/권한/라이선스 | API key를 저장소에 기록하지 않음. 비공개·개인·금융·의료 등 민감자료는 기본적으로 라우팅하지 않음. 라이선스는 별도 공식 확인 전 단정하지 않음 |
| ⑫ 비용 상태 | `유료` — 추가 API 비용이 발생하는 구조로 현재 기본 추천/자동 연결 대상에서 제외 |

## 현재 설치 정보

원본 기록은 `01_CONTROL/AI_INSTALLATIONS.md`를 기준으로 한다.

- package: `jev-router@0.2.0`
- 위치: `C:\Users\user\AppData\Roaming\npm`
- entry point: `jev-codex.cmd`, `jev-claude.cmd`
- API key: 미설정
- 실제 모델 선택/작업 왕복: 미검증
- 현재 과금: 없음

## 운영 판단

사용자 기본 정책상 추가 결제가 필요한 유료 도구는 명시 요청 전에는 추천·활성화·연결하지 않는다. 따라서 설치되어 있다는 사실과 채택/사용 중이라는 상태를 분리한다.

현재 상태는 **설치 흔적은 유지하되 비활성·미채택**이다. 무료/오픈소스 또는 기존 요금제 내에서 같은 목적을 충분히 달성할 수 있다면 그쪽을 우선한다.

사용자가 향후 명시적으로 유료 API 사용을 승인한 경우에만 비민감 짧은 작업으로 `jev-codex`와 일반 `codex`를 비교하고, 비용·한국어/CJK 라우팅 품질·실제 절감 효과를 확인한 뒤 채택 여부를 다시 판단한다.
