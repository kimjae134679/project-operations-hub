- **HealthAPK** — local-first, 실제 사용자 흐름, 재실행 persistence, standalone/offline 분리
- **Investment-Lab** — one-click entry, safe-idle/blocked/error 구분, changed HEAD 재검증
- **ChungYack** — content/data와 native shell 분리, persistent key 보호, backup→migrate→restore
- **PhoneLOL** — exact baseline SHA, minimal patch, static vs physical evidence 분리
- **Market Radar** — desktop+phone QA, generated data와 hand-tuned UI 분리, canonical live state
- **SideMemojang** — explicit target delete, context menu, IME, uninstall != user-data deletion
- **FinanceOne** — design→feature-preservation→implementation→regression, migration-first, signing 보존
- **ASCII Aquarium** — human status/raw log 분리, updater READY handshake, Korean/space path QA
