# Document Model

| 정보 | 원본 위치 |
|---|---|
| 사용자 공통 정책 | `01_CONTROL/USER_POLICIES.md` |
| 도구 채택 상태 | `01_CONTROL/TOOLS.md` |
| 프로젝트 등록/주소 | `01_CONTROL/PROJECT_REGISTRY.md` |
| 프로젝트 목적/현재 상태 | 실제 프로젝트 README |
| 정확한 명령/경로/SDK/권한 | 실제 프로젝트 AGENTS |
| 공통 검증 패턴/팁 | `03_KNOWLEDGE/` |
| 프로젝트 간 대화 | `04_COMMUNICATION/threads/` |
| 종료/교체된 과거 문서 | `99_ARCHIVE/` 또는 Git 이력 |

같은 정보를 여러 곳에 복사해서 동기화 문제를 만들지 않습니다. 상위 허브의 프로젝트 파일은 **포인터/요약**만 유지합니다.
