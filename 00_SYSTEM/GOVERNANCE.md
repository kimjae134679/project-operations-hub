# Governance

## 목적과 범위

이 허브는 현재 ChatGPT 프로젝트에서 여러 실제 프로젝트를 이어서 작업하기 위한 컨트롤러입니다.

- 현재 프로젝트 안에서만 적용합니다.
- 다른 ChatGPT Project나 독립 채팅의 전역 규칙으로 간주하지 않습니다.
- 허브는 정책·연결·인수인계를 관리하며 실제 프로젝트 저장소를 대체하지 않습니다.

## 우선순위

1. 현재 채팅의 사용자 최신 지시
2. 실제 대상 프로젝트의 현재 저장소 tip과 README/AGENTS
3. `01_CONTROL/USER_POLICIES.md`
4. 이 허브의 `AGENTS.md`
5. 커뮤니케이션 채널의 과거 기록과 제안

오래된 허브 요약이나 인수인계가 실제 저장소의 현재 상태와 다르면 실제 저장소를 우선합니다.

## 핵심 원칙

- 최종 컨트롤권은 사용자에게 있습니다.
- 다른 프로젝트를 참고했다는 이유만으로 수정 권한이 생기지 않습니다.
- 정책과 실행 정보를 여러 파일에 중복 저장하지 않습니다.
- 비밀값은 저장소에 기록하지 않습니다.
- 확인되지 않은 상태를 성공으로 표현하지 않습니다.
- 요구사항·검증·보안·데이터 보존·복구 가능성을 줄여서 구현을 간단하게 만들지 않습니다.
- 필요한 문서만 읽고 같은 자료를 반복해서 불러오지 않습니다.

## 현재 상태와 기록

- 실제 코드·버전·명령·Known-Good → 실제 프로젝트 저장소
- 공통 정책·등록 → `01_CONTROL/`
- 사용자 요약 → `000_사용자용/`
- 과거 진행 과정 → `04_COMMUNICATION/`

커뮤니케이션 기록은 현재 상태의 원본이 아닙니다. 프로젝트를 재개할 때는 최신 저장소 상태를 먼저 확인합니다.

## AGENTS 정리

AGENTS는 현재 실행 규칙만 유지합니다. 해결된 임시 우회법, 오래된 경로, 중복 규칙은 제거하고 과거 내용은 Git 이력이나 Archive에서 확인합니다.

## 인수인계 필수 정보

- 실제 변경 대상과 결과
- 기준 commit 또는 산출물
- 수행한 검증과 미실행 검증
- 남은 문제와 다음 작업
- AI가 설치·생성한 프로그램과 작업 폴더의 실제 위치
- 기본 관리 루트 `C:\Program Files\_My\AI` 준수 여부와 예외 이유
- launcher/config의 경로 의존성과 이동 시 갱신 항목
