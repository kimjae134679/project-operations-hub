# Governance

## 목적
여러 프로젝트를 새 채팅/새 AI에서도 빠르게 이어가되 문서가 실제 작업보다 앞서지 않게 합니다.

## 우선순위
1. 현재 채팅의 사용자 최신 지시
2. 해당 프로젝트 사용자 README
3. `01_CONTROL/USER_POLICIES.md`
4. 해당 프로젝트 AGENTS
5. 이 허브의 `AGENTS.md`
6. 커뮤니케이션 채널의 제안

## 핵심 원칙
- 최종 컨트롤권은 사용자에게 있습니다.
- 정책과 실행정보를 한 파일에 중복 저장하지 않습니다.
- 비밀값은 저장소에 기록하지 않습니다.
- 확인되지 않은 상태를 성공으로 표현하지 않습니다.
- 구현을 최소화해도 요구사항·QA·보안·데이터 보존·rollback은 줄이지 않습니다.
- 다른 프로젝트를 참고했다는 이유만으로 수정 권한까지 있다고 해석하지 않습니다.

## AGENTS 정리
AGENTS는 영구 역사서가 아닙니다. 해결된 임시 우회법, 오래된 도구/경로, 중복 규칙은 제거합니다. 현재 유효한 명령·권한·Known-Good·검증법은 보존합니다. 필요하면 README/실제 저장소/현재 검증 사실에서 AGENTS를 재생성합니다.
