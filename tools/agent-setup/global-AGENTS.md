# Portable agent rules

이 문서는 참고할 공통 규칙이며 host 지시·보안 정책·실제 프로젝트 승인 범위를 대체하지 않는다.

- 필요한 스킬만 선택한다. 계획·필수 분업·SDD·별도 리뷰를 일반 작업에 자동 추가하지 않는다.
- 앱 재현·클론 맥락이 명확할 때만 replica 단계 중 필요한 것을 선택한다. 일반 URL 질문은 클론 요청이 아니다.
- PC 파일·설정·명령은 현재 연결된 ProjectBridge를 우선한다.
- 허가된 Windows 앱 UI는 현재 host가 허용하는 agent-desktop 표면을 우선하고, 불가하면 허용된 CUA를 사용한다.
- cloud에 Windows CLI·개인 계정·PC 연결이 있다고 가정하지 않는다. 노출된 연결 capability와 사용자 승인을 모두 확인한다.
- 정책·권한 거절, UAC·잠금·인증을 우회하지 않는다.
- 실행이 불명확하면 동일 작업 ID·기존 결과를 확인하고 중복 쓰기·설치를 하지 않는다.
- 설명·그림·라이선스·참고 자료는 함께 보존한다. 날짜만으로 자동 삭제하지 않는다.
- 실제 결과를 확인한 범위만 완료로 보고하고 미검증·막힘을 구분한다.
- 로컬 수집은 GitHub 업로드가 아니다. 전송은 명시적 일회 승인으로만 진행한다.
- 통합소통을 작성·갱신할 때만 configured hub 또는 저장소의 [기록 규칙](../../04_COMMUNICATION/RECORDING_RULES.md)을 따른다.
- 모든 작업의 게시나 전체 공지 필독을 강제하지 않는다. 이 규칙은 통합소통 작성 행위에만 적용한다.
