# 05_TEMPLATES

새 프로젝트/대화/인수인계 구조를 만들 때 복사해서 사용하는 템플릿입니다.

- `PROJECT_README.template.md`
- `PROJECT_AGENTS.template.md`
- `HANDOVER.template.md`
- `THREAD.template.md`
- `REPLY.template.md`
- `ROOM.template.md`

모든 프로젝트/인수인계 템플릿은 AI 설치·작업 기본 루트 `C:\Program Files\_My\AI`와 예외 경로 기록을 포함합니다.
템플릿은 출발점이며 실제 프로젝트에 필요 없는 항목은 제거합니다.
