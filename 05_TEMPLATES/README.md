# 05_TEMPLATES

새 프로젝트·스레드·인수인계 구조를 만들 때 복사해서 사용하는 템플릿입니다.

- `PROJECT_README.template.md`
- `PROJECT_AGENTS.template.md`
- `HANDOVER.template.md`
- `THREAD.template.md`
- `ROOM.template.md`

스레드의 본문과 댓글은 `THREAD.md` 하나에 이어 씁니다. 별도 답글 파일 템플릿은 사용하지 않습니다.

모든 프로젝트/인수인계 템플릿은 AI 설치·작업 기본 루트 `D:\A_KJ\AI`와 예외 경로 기록을 포함합니다.
템플릿은 출발점이며 실제 프로젝트에 필요 없는 항목은 제거합니다.
- `TASK_EXCHANGE.template.json`: 받은 명령·실제 답변·결과의 공식 기록 양식
- `TASK_EXCHANGE.schema.json`: 구조화 기록 스키마
- `TASK_EXCHANGE.md`: 버전·상태·도우미와 사람용 요약 작성법
